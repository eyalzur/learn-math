## מנוי הורים — שתי אפליקציות נבנו (PR #137), ממתינות להגדרת שרת
שתי אפליקציות נפרדות להתקנה: ילדים (`/next/`) והורים (`/next/parents/`), עם שרת ב-Cloud Run ו-Firestore. הילד יוצר פרופיל בעצמו ומקליד קוד של ההורים; ההורה רואה התקדמות לפי נושא; הזמנות (ילד, הורה נוסף, מכשיר חדש) בקוד, QR ווואטסאפ. מנוי (שבוע חינם, 10/30 ₪, נעילה) בנוי אבל **כבוי** (`PAYWALL`); בלי מחירים בינתיים. מסמכים: `docs/features/parent-subscription/`.
**לא נבדק:** כניסה עם Firebase (גוגל / קישור במייל), Firestore אמיתי, הפריסה, התקנה בפועל על טלפון, פתיחת וואטסאפ.
**נדחו (לא נבנו):** לוח זמנים, תזכורות והתראות; ספק תשלום (כנראה Cardcom); PIN לילדים גדולים; ניקוי תקופתי של פרופילים שלא חוברו להורה; נוסח פרטיות ובדיקה משפטית (מגיע מהמשתמש); הוצאת בנקי השאלות מחבילת הלקוח.
**עוד אחר כך:** שיפור UI לשתי האפליקציות — `kb/process/ui-polish.md`.

## רק המשתמש יכול לעשות
- **הגנת בראנץ'.** `main` נפרס אוטומטית ועדיין אין דרישה שהבדיקות יעברו לפני מיזוג: Settings → Branches → `main` → require `check` + `test`.
- **ניקוי משאבי Claude ישנים.** אין היום קוד שקורא ל-Claude. אפשר למחוק את ה-federation rule ב-Anthropic Console ואת חשבון השירות `notebook-server-claude@learn-math-506923` (ולבדוק שה-pool של WIF עדיין נחוץ לפריסת שרת ההקראה).
- **שתי האפליקציות החדשות:** ההגדרה החד-פעמית ב-`api/README.md` (Cloud Shell: Firestore וחשבון שירות; Firebase: גוגל וקישור במייל; secret `CHILD_TOKEN_SECRET`; הרצת פריסה; משתנים `NEXT_API_URL` ו-`NEXT_FIREBASE_CONFIG`). אחרי זה שני הקישורים להתקנה עובדים. נוסח פרטיות ודרישות משפטיות — כשמתקדמים.

## תוכן
- גיוון בשאלות חזקות אדפטיביות: `2²` חוזר 3 פעמים מתוך 12; לשקול חלון ללא חזרות; מאגר בסיסים
  2–9 ב-`src/data/adaptivePowers.ts` (דפוס 1).
- הסבר העלאה בחזקה שלישית שלב אחר שלב (4×4=16 ואז 16×4=64, שיטה מאונכת).

- תיקון הסבר הפונקציה הלינארית: הרמזים חוזרים על "איך פותרים?", השלבים צפופים, צריך הפרדה
  בין שורות.
