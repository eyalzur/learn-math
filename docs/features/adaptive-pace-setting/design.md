# קצב התקדמות בקושי — Design

## Overview
בורר שלושה-מצבים חדש בתוך דיאלוג ⚙️ הקיים, באותה צורה בדיוק כמו הבוררים הקיימים
שם (עוצמת זום-ההחזקה, מהירות הזזת התצוגה וכו') — אייקון, כותרת, הערה קצרה, ושלושה
כפתורים לבחירה. הדיאלוג הקיים מציג היום את כל ההגדרות תמיד יחד (גם הגדרות
שרלוונטיות רק למחברת מופיעות גם מחוץ למחברת) — הבורר החדש מצטרף לאותה רשימה
ומוצג באותו אופן, בלי תנאי נוסף לפי מסך או נושא.

## Screens / States
דיאלוג ⚙️ הקיים (נפתח מכל מסך תרגול או ממסך בחירת הנושא, כמו היום) — בלוק חדש
בתוך `settings-body`, באותו מקום שבו שאר הבוררים נמצאים.

```
⚙️ הגדרות
...
┌──────────────────────────────────────┐
│ 🎯  קצב שינוי הקושי                  │
│     כמה מהר רמת הקושי עולה ויורדת    │
│                                        │
│   [ אטי ]  [ בינוני ]  [ מהיר ]       │
└──────────────────────────────────────┘
...
[ סגירה ]
```

כש"בינוני" נבחר (ברירת המחדל) הכפתור שלו מסומן (`aria-pressed`), בדיוק כמו בשאר
הבוררים בדיאלוג הזה.

## Copy
- כותרת הבלוק: **"קצב שינוי הקושי"**
- הערה: **"כמה מהר רמת הקושי עולה ויורדת"**
- תוויות שלושת הכפתורים: **"אטי"** / **"בינוני"** / **"מהיר"** — משתמש באותה
  מילה "בינוני" שכבר קיימת בכל שאר הבוררים בדיאלוג הזה (לא "רגיל", כדי לא
  להוסיף מילה שלישית לאותו מושג; ברירת המחדל וההתנהגות הנוכחית לא משתנות,
  רק התווית).
- אייקון: 🎯 (לא בשימוש כבר באף בורר קיים בדיאלוג הזה).

## Interaction Flow
1. המשתמש/ת פותח/ת ⚙️ מכל מסך תרגול של נושא אדפטיבי.
2. רואה את הבלוק "קצב שינוי הקושי" לצד שאר ההגדרות (הרלוונטיות למצב הנוכחי).
3. לוחצ/ת על אחד משלושת הכפתורים — הבחירה מסומנת מיד (כמו שאר הבוררים: אין כפתור
   "שמירה" נפרד, הבחירה נכנסת לתוקף מיד עם הלחיצה, כולל על שאלה שכבר באמצע
   תרגול פתוח).
4. סוגר/ת את הדיאלוג ("סגירה" או קליק מחוץ לכרטיס) — ההגדרה נשארת כמו שאר
   ההגדרות בדיאלוג הזה (נשמרת, שורדת רענון/סגירת דפדפן).

## Accessibility / RTL notes
אין כאן טקסט מספרי/חשבוני שדורש כיוון LTR — שלושת הכפתורים הם מילים עבריות
בלבד, מוצגים באותה שורת `role="group"` + `aria-pressed` לכל כפתור, בדיוק כמו
`hold-zoom-options`/`pan-speed-options` הקיימים (RTL טבעי, בלי התנגשות).

## Acceptance Criteria Check
- קיים בורר חדש בדיאלוג ⚙️ עם שלוש אפשרויות (אטי/בינוני/מהיר): **yes** — ראו
  Screens/States ו-Copy למעלה.
- "בינוני" הוא ברירת המחדל וזהה בהתנהגותו להיום: **yes** — זו קביעת מוצר
  שהעיצוב לא נוגע בה; הבורר רק קובע את התווית הנבחרת כברירת מחדל.
- ההתנהגות המספרית של כל רמה (4/2 באטי, 2/1 בבינוני, 1/1 במהיר): **yes, ללא
  שינוי** — זו החלטת מוצר קיימת; אין לה השלכה על המסך עצמו.
- הבורר חל על כל הנושאים האדפטיביים, לא רק מחברת: **yes** — ראו Overview: הבלוק
  מוצג תמיד בדיאלוג ⚙️ בכל מסך, כמו כל שאר הבוררים שם.
- משתנה מיד, גם על תרגול פתוח: **yes** — ראו Interaction Flow סעיף 3.
- ההגדרה נשמרת לאורך זמן: **yes** — אותו מנגנון שמירה כמו שאר ⚙️ (לא ממומש
  כאן, זו קביעת עיצוב בלבד שההתנהגות זהה לדפוס הקיים).
