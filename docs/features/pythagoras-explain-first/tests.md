# פיתגורס — מסבירים לפני שפותרים — Tests

## Coverage
שינוי תוכן בלבד — אין קריטריון שדורש בדיקת `e2e` ייעודית. הכיסוי הקיים
ב-`content.spec.ts` (`"has an explanation with steps and an analogy"`,
`"keeps arithmetic out of the prose field"`) ממשיך לרוץ על שמונה השאלות
ועובר: כל שאלה עדיין מחזיקה `steps` לא-ריקים ו-`analogy`, ומשפטי הפתיחה
החדשים אינם מכילים ריצת ספרות עם פעולה.

**מה נבדק ידנית:** שכל אחת משמונה השאלות פותחת עכשיו במשפט שאומר איזו
צורה זו ומה מחפשים, לפני החישוב הראשון — ראו `design.md`.
