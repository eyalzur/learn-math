# פיתגורס — מסבירים לפני שפותרים — Design

## Overview
אין מסך חדש. שלב אחד נוסף בראש `explanation-step` הקיים — אותו רכיב,
אותו עיצוב, רק עוד שורה ראשונה.

## Copy

ארבעה תבניות פתיחה, אחת לכל צורת שאלה, בהתאמה למה שכבר קיים ב-`h1`/`h4`:

| צורת שאלה | שאלות | משפט פתיחה |
|---|---|---|
| ניצב מהיתר וניצב נתון | `h6` | "הניצב בריבוע שווה להיתר בריבוע פחות הניצב הידוע בריבוע" (זהה ל-`h1`) |
| אלכסון ממלבן דרך היקף | `h2`,`h7` | "האלכסון הוא היתר של משולש ישר זווית שהניצבים שלו הם אורך המלבן ורוחבו — קודם צריך את הרוחב" |
| סולם על קיר | `h3`,`h8` | "הסולם הוא היתר, והקיר והקרקע הם שני הניצבים — מחפשים את הניצב שלא נתון" (מרחיב את `h3` הקיים) |
| ניצבים שווים משטח | `h9` | "שטח משולש ישר זווית זה מכפלת הניצבים חלקי 2" (זהה ל-`h4`) |
| הפרש אלכסון-מול-היקף | `h5`,`h10` | "קודם מחשבים את אורך האלכסון — היתר של המשולש שהצלעות הן הניצבים שלו — ואז משווים אותו לדרך לאורך שתי הצלעות" |

**כל תבנית נלקחת ממה שכבר עבד** (`h1`,`h4`,`h3`) ולא הומצאה מחדש — כך
שהניסוח עקבי בין השאלות באותה צורה, בדיוק כפי שהמורה חוזרת על אותו משפט
כלל בכל שאלה מאותו סוג (העיקרון שכבר נקבע ב-`numberLine`).

## Interaction Flow
זהה לגמרי. שלב הפתיחה מוצג בדיוק כמו כל `explanation-step` אחר —
ברצף, לפני שלבי החישוב, ונקרא בקול באותו סדר.

## Accessibility / RTL notes
אין ביטוי חשבוני במשפטי הפתיחה (אין ספרות עם פעולה), ולכן אין סיכון
כיווניות חדש — הם עברית רגילה, כמו כל `label` בלי `math`.

## Acceptance Criteria Check
- שלב פתיחה שאינו חישוב, לכל אחת משמונה השאלות: **yes**.
- `h1`,`h4` ללא שינוי: **yes**.
- עקביות בין שאלות מאותה צורה: **yes** — אותו משפט מילה במילה לכל זוג/שלישייה.
