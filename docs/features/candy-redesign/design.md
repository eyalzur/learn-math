# עיצוב חדש — ממתקייה (סגול כהה) — Design

## Overview
מחליפים את ערכי העיצוב הגלובליים הקיימים (`src/index.css`'s `:root`, וכל מה שנשען
עליהם ב-`App.css`) בסט אחד קבוע, בהשראת כיוון "ממתקייה" מגלריית הקונספטים: רקע ורוד
בהיר, טקסט סגול-בורדו כהה, גופן כותרות עגול וחמוד, accent פינק בוהק, פינות מעוגלות
גדולות, ומסגרת מנוקדת סביב אזור הכתיבה במחברת. אין מסך חדש ואין הבחנת light/dark —
זה הופך פשוט להיות איך שהאפליקציה נראית.

**עדכון (אחרי ריוויו חי):** ניסיון ראשון החשיך את הרקע (סגול כהה, `#2a1b40`) כדי
"לא להיות עדין מדי" — אבל זה יצר תלונות חוזרות על ניגודיות/סינוור בטקסט. הוחזר
לפלטת הקונספט המקורי כמו שהוא (רקע ורוד בהיר, טקסט כהה) — הטבלה למטה היא הגרסה
הסופית שבאמת נשלחת.

## צבעים — ערכים קונקרטיים

| טוקן | ערך ישן | ערך חדש (ממתקייה) |

| `--text` | `#6b6375` | `#7a4568` (סגול-ורוד כהה, לטקסט רגיל) |
| `--text-h` | `#08060d` | `#5c2a52` (סגול-בורדו כהה, לכותרות) |
| `--border` | `#e5e4e7` | `#ffd6ea` (ורוד בהיר) |
| `--code-bg` | `#f4f3ec` | `#ffffff` (כרטיס לבן) |
| `--accent` | `#aa3bff` | `#ff6fae` (פינק עז — מהקונספט המקורי) |
| `--accent-bg` | `rgba(170,59,255,0.1)` | `rgba(255,111,174,0.12)` |
| `--accent-border` | `rgba(170,59,255,0.5)` | `rgba(255,111,174,0.5)` |
| `--notebook-grid` | `#b8d4f0` | `#ffb8d9` (קו-רשת ורוד רך, נראה על דף הכתיבה) |

`--notebook-question-ink` ו-`--social-bg`/`--shadow` לא ברשימת המשתנים שהוחלט לשנות
ב-product-spec — נשארים באותו רעיון (ערך קרוב לישן, מותאם לרקע הבהיר החדש).

**ניגודיות (WCAG AA, לפחות 4.5:1):**
- `--text-h` (`#5c2a52`) על `--bg` (`#fff1f7`): כ-7.3:1 — עובר בנוחות.
- `--text` (`#7a4568`) על `--bg`: כ-5.6:1 — עובר.
- רקע בהיר + טקסט כהה הוא קל להשיג ניגודיות טובה בו מעצם הבנייה — זו בדיוק הסיבה
  שחזרה לקונספט המקורי פתרה את הבעיה בלי צורך לכוון כל ערך בנפרד.

**מצב light/dark כהה היום** (ה-`@media (prefers-color-scheme: dark)` הקיים ב-
`src/index.css`): מתבטל — הערכים החדשים למעלה הם היחידים, בלי בלוק נפרד למצב כהה.
זו ההחלטה שאושרה בצ'אט (עיצוב אחיד קבוע, בלי הבחנה בין light ל-dark).

## Screens / States
משפיע על **כל** המסכים הקיימים, בלי מסך חדש:

- **בחירת תלמיד/ה** — הרקע הכהה-סגול, כרטיסי התלמיד/ה בפינות מעוגלות גדולות יותר,
  כותרת "מי לומד היום?" בגופן עגול.
- **בחירת כיתה/נושא** — אותו טיפול: כרטיסי נושא/כיתה בפינות מעוגלות, כותרות בגופן
  העגול.
- **מסך תרגול** — תיבת השאלה (`.problem-box`) ממשיכה להיראות כמו תיבה מובחנת (לא
  צבע-רקע-שקוף), רק עם הצבעים/פינות החדשים; כפתורי פעולה ("שלח למורה" וכו׳) הופכים
  לכפתורי-פיל (pill) מלאים בצבע ה-accent.
- **המחברת** — קו-הרשת הופך ללבנדרי (`--notebook-grid` החדש); **אזור הכתיבה עצמו
  מוקף במסגרת מנוקדת (dotted, כ-2px, בצבע `--accent`)** במקום מסגרת רגילה — זה הפרט
  החזותי המזוהה ביותר עם "ממתקייה". משטח הנייר/הדיו עצמם (לבנים, לכתיבה) **לא**
  משתנים — זה תמיד היה עיצוב-נייר קבוע ונפרד מהתמה, לא קשור לטוקנים האלה.
- **דיאלוגים קיימים** (⚙️ הגדרות, לוג גרסאות אם קיים, וכל דיאלוג אחר שנשען על
  `--bg`/`--border`/`--text`) — עוברים אוטומטית עם שינוי הטוקנים, בלי צורך במסך
  נפרד.

כל הכרטיסים/הדיאלוגים הראשיים מקבלים `border-radius` גדול משמעותית מהיום (כיוון
"18px"-ish מהקונספט, לא מספר מדויק — tech-lead/developer יתאימו לכל קונטיינר לפי
הגודל שלו, אבל כולם צריכים להרגיש "עגולים ורכים", לא פינות חדות כמו היום).

## Copy
אין מחרוזות עברית חדשות או משתנות — זה שינוי ויזואלי בלבד.

## Interaction Flow
אין שינוי בזרימה, בניווט, או בהתנהגות — הכל קורה אוטומטית בטעינה (אין אנימציה, אין
מעבר, אין פעולת משתמש נדרשת). המשתמש פשוט פותח את האפליקציה ורואה את העיצוב החדש
בכל מסך, בלי הבדל בין ביקור ראשון לביקור חוזר, ובלי קשר להעדפת light/dark של
המכשיר.

## Accessibility / RTL notes
- `.problem-box`/`.problem-text` (הביטויים החשבוניים, למשל "7 + 8 =") נשארים
  `direction: ltr; unicode-bidi: isolate` כפי שהם היום — העיצוב החדש לא נוגע בכיוון,
  רק בצבע/גופן/רקע של התיבה שמסביב.
- גופן הכותרות המוצע ("Varela Round") נבדק חזותית בגלריית הקונספטים (קונספט
  "ממתקייה") עם טקסט עברי אמיתי ("מי לומד היום?") ומוצג תקין — יש לו תמיכה בעברית.
  "Rubik" (גוף הטקסט) נמצא כבר בשימוש נרחב באתרים עבריים ותומך עברית במלואה.
- ניגודיות הטקסט על הרקע הכהה נבדקה ידנית למעלה (טבלת הצבעים) — מעל סף 4.5:1 לכל
  שילוב טקסט/רקע. tech-lead/developer צריכים לוודא בפועל (בדיקה חזותית בדפדפן) שגם
  מצבים נגזרים (למשל `--accent-bg` כרקע ל-badge עם `--text` כטקסט) לא יוצרים ניגודיות
  נמוכה בטעות.

## Acceptance Criteria Check
- מסכים עיקריים מציגים רקע ורוד בהיר, בלי תלות ב-light/dark: yes — `:root` יחיד, בלי
  בלוק `prefers-color-scheme` נפרד.
- כותרות בגופן עגול, גוף טקסט קריא: yes — Varela Round לכותרות, Rubik לגוף.
- כרטיסים/כפתורים עם פינות מעוגלות בבירור: yes — `border-radius` גדול לכל קונטיינר
  ראשי, כפתורי-פיל לפעולות.
- אזור הכתיבה במחברת מוקף במסגרת מנוקדת accent: yes — מתואר בפירוט בסעיף Screens.
- ניגודיות טקסט עומדת ב-WCAG AA: yes — מאומת בטבלת הצבעים למעלה (כל הצמדים מעל
  4.5:1).
- ביטויי חשבון נשארים LTR: yes — `.problem-box` לא משתנה בכיוון, רק בעיצוב.
- אין בורר/הגדרה/localStorage לעיצוב: yes — אין מסך או state חדש בתכנון הזה כלל.
- אין שינוי בתוכן/לוגיקה: yes — כל השינוי מוגבל לטוקני CSS וקלאסים קיימים.
