# אבחון קשיים לאורך זמן — Design

## Overview
בראש מסך "ההתקדמות שלי" (`History.tsx`), מעל רשימת התרגולים הקיימת, מופיע
כרטיס נפרד לכל נושא שזוהה כ"נתקע/ת בו" — עם משפט קצר וכפתור שמתחיל תרגול
חדש באותו נושא. בלי נושא שתואם — שום דבר לא מופיע, המסך נשאר כמו שהוא היום.

## Screens / States
מסך "ההתקדמות שלי" — אותו מסך בדיוק, עם בלוק חדש אופציונלי בין הכותרת
("ההתקדמות שלי") לרשימת התרגולים:

```
← חזרה                                    שלום רותם!

ההתקדמות שלי

┌──────────────────────────────────────────────┐
│ 💡  נראה שאחוזים קצת מאתגר השבוע              │
│     [ לתרגל עכשיו ]                           │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│ 💡  נראה שמשוואות קצת מאתגר השבוע             │
│     [ לתרגל עכשיו ]                           │
└──────────────────────────────────────────────┘

[רשימת התרגולים הקיימת, בלי שינוי]
```

כרטיס אחד לכל נושא שתואם את ההגדרה — יכול להיות יותר מאחד, מסודרים לפי
אותו סדר שההיסטוריה עצמה מסודרת בו (העדכני ביותר קודם: הנושא שה"תרגול
האחרון" שלו הכי קרוב מופיע ראשון).

## Copy
- משפט הכרטיס: **"נראה ש<נושא> קצת מאתגר השבוע"** — לדוגמה "נראה שאחוזים
  קצת מאתגר השבוע". "השבוע" הוא ניסוח רך, לא תלוי בחישוב תאריכים בפועל
  (שלושת התרגולים האחרונים יכולים להיות גם מפני שבועיים) — זו מגבלה
  מכוונת: הניסוח רך בכוונה כדי לא להישמע כמו הבטחה מדויקת לגבי זמן.
- כפתור: **"לתרגל עכשיו"**
- אייקון: 💡 (אותו אייקון-מושג "תובנה" כמו ברמזים, לא צבע-אזהרה אדום —
  זה עידוד למיקוד, לא ציון שלילי).

## Interaction Flow
1. התלמיד/ה (או ההורה) נכנסים ל"ההתקדמות שלי", כמו היום.
2. אם יש נושא/ים שתואמים את ההגדרה, הכרטיס/ים מופיעים מיד בטעינת המסך —
   אין צורך בפעולה נוספת לגלות אותם.
3. לחיצה על "לתרגל עכשיו" פותחת תרגול חדש באותו נושא — אותה נקודת-כניסה
   בדיוק שהייתה נפתחת לו היו לוחצים על כרטיס הנושא ברשימת הנושאים (נושא
   אדפטיבי מתחיל תרגול ישר; נושא עם רמות/סגנונות פותח את מסך הבחירה שלו —
   זה כבר ההתנהגות הקיימת של כניסה לנושא, לא משהו חדש).
4. אין צורך לחזור למסך "ההתקדמות שלי" כדי שהכרטיס ייעלם — הוא מחושב מחדש
   בכל טעינה של המסך, כך שבפעם הבאה שחוזרים אליו (אחרי תרגול חדש וטוב
   יותר), הוא פשוט לא יהיה שם.

## Accessibility / RTL notes
אין תוכן מספרי/LTR חדש כאן — שם הנושא (`topicTitle`) הוא תמיד עברית, בדיוק
כמו שהוא כבר מוצג היום בכל שורת היסטוריה קיימת (`.history-what`). שום
ביטוי חשבוני לא מופיע בכרטיס.

## Acceptance Criteria Check
- "שלושה תרגולים רצופים מתחת ל-70% מסמנים נושא, פחות משלושה לא": **yes** —
  זו לוגיקת-נתונים טהורה, אין לה ביטוי עיצובי; הכרטיס פשוט מופיע/לא מופיע
  לפי התוצאה.
- "תרגול טוב אחד שובר את הרצף": **yes** — אותה סיבה, חישוב-נתונים בלבד.
- "הודעה נפרדת לכל נושא תואם, עם קישור שמתחיל תרגול": **yes** — ראו
  Screens/States ו-Interaction Flow.
- "בלי נושא תואם, המסך נראה כמו היום": **yes** — הבלוק כולו מותנה בקיום
  לפחות נושא אחד; בלי זה, שום דבר לא נוסף.
- "ההודעה נעלמת אחרי שיפור, בפעם הבאה שהמסך נטען": **yes** — ראו
  Interaction Flow סעיף 4.
