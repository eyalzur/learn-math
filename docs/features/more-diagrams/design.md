# ציורים לשאר הנושאים — Design

## Overview
שש צורות חדשות שיושבות באותו מקום ובאותה שפה חזותית של עיגול השברים: בראש קופסת
ההסבר, מלא מול ריק, כיתוב אחד מתחת. מה שמשתנה בין נושא לנושא הוא הצורה בלבד.

## Screens / States

### מה קבוע בכל שבע הצורות
| | |
|---|---|
| מיקום | בראש קופסת "איך פותרים?", לפני השלבים |
| רוחב מרבי | `280` פיקסלים, מתכווץ עם המסך |
| קו | צבע הטקסט הראשי, עובי `1.5` |
| "החלק שבשאלה" | מלא בסגול; השאר ריק. **הבדל בערך ולא בגוון** |
| מספרים | `15` פיקסלים, `direction: ltr` ובידוד |
| כיתוב | שורה אחת מתחת, שהיא גם הטקסט לקורא מסך וגם מה שמוקרא |

**עיגול השברים שכבר נבנה נשאר `180` מרובע** — הוא הצורה היחידה שאין לה ציר ארוך.

---

### 1 · ציר מספרים — מספרים עד `20`
`איזה מספר בא אחרי 12?`

```
        10    11    12    13    14    15
    ────┼─────┼─────●─────★─────┼─────┼────►
                    מ           אל
```

`●` המספר שבשאלה, `★` התשובה. חץ בקצה כדי שיהיה ברור שהציר ממשיך.

**הציר אינו מראה `0` עד `20`.** ב-`280` פיקסלים זה `21` סימונים במרווח של `13`
פיקסלים, ומספר דו-ספרתי לא נכנס. הוא מראה **חלון סביב השאלה** — המספרים שבשאלה
ובתשובה, ועוד אחד או שניים משני הצדדים, לפחות `5` סימונים.

זו גם ההחלטה הפדגוגית הנכונה: השאלה היא על השכנים, לא על כל הטווח.

**הכיוון: משמאל לימין, עולה.** ראו הערות הכיווניות — זו ההכרעה החשובה כאן.

### 2 · קופסאות של עשר — עשרות ויחידות
`כמה יחידות יש במספר 13?`

```
   ┌───┬───┬───┬───┬───┐          ●  ●  ●
   │ ● │ ● │ ● │ ● │ ● │
   ├───┼───┼───┼───┼───┤        שלוש בודדות
   │ ● │ ● │ ● │ ● │ ● │
   └───┴───┴───┴───┴───┘
      קופסה מלאה
```

קופסה של `2×5` מלאה, והבודדות לצידה. הצד שהשאלה שואלת עליו מסומן במילוי; השני
בקו בלבד.

### 3 · צורה עם מידות — שטח והיקף
`שטח מלבן שאורכו 5 ורוחבו 4`

```
            5
      ┌───────────┐
      │           │
    4 │           │      ← המילוי מסמן שטח; היקף מסמן את הקו בלבד
      │           │
      └───────────┘
```

ארבע צורות: מלבן, ריבוע, משולש (עם גובה מקווקו), מעגל (עם רדיוס). **שאלה הפוכה
— "שטח `12` ורוחבו `3`, מה האורך?" — מסמנת את הצלע החסרה ב-`?`.**

**שטח מסומן במילוי, היקף בהדגשת הקו המקיף.** אותה צורה, שני סיפורים שונים, ובלי
זה התלמיד לא רואה במה השאלה עוסקת.

### 4 · משולש ישר זווית — פיתגורס
`במשולש ישר זווית הניצבים הם 3 ו-4. מה אורך היתר?`

```
      │╲
      │  ╲   5
    4 │    ╲
      │      ╲
      └┐───────╲
       3
```

הזווית הישרה מסומנת בריבוע קטן. **המשולש מצויר בפרופורציה אמיתית**, מוקטן כך
שהניצב הארוך תופס אורך קבוע.

זו הצורה היחידה שבה פרופורציה שקרית מטעה ממש: משולש `5`,`12` שמצויר כמעט
שווה-שוקיים גורם ליתר להיראות לא נכון, והמשפט כולו הוא טענה על היחס ביניהם.

### 5 · רצועה מתוך מאה — אחוזים
`כמה זה 25% מ-80?`

```
   ┌────────┬───────────────────────────────┐
   │████████│                               │
   └────────┴───────────────────────────────┘
      25%              מתוך 80
```

רצועה אחת. החלק הצבוע הוא האחוז, וקווי עזר דקים כל `25%` כדי שהעין תוכל לאמוד.

### 6 · שתי רצועות — יחס
`היחס הוא 2 ל-3. אם החלק הראשון הוא 10, כמה השני?`

```
   ┌─────┬─────┐                    2 חלקים
   │█████│█████│
   └─────┴─────┘

   ┌─────┬─────┬─────┐              3 חלקים
   │     │     │     │
   └─────┴─────┴─────┘
        כל חלק שווה 5
```

שתי רצועות באותו גודל יחידה. **מה שהיחס אומר נהיה נראה לעין**: אותה לבנה, מספר
שונה שלה.

### 7 · ישר על צירים — פונקציה קווית
`בפונקציה y = 2x + 1, כמה y כאשר x שווה 3?`

```
    y
    │        ╱
   7│      ●
    │    ╱
    │  ╱
   1│╱
    └────┬────── x
         3
```

ציר עם הישר, והנקודה מסומנת. הצירים מסומנים רק בערכים שבשאלה ובתשובה, לא בסקאלה
מלאה.

---

### מצב ללא ציור
זהה להיום, בכל נושא ובכל שאלה שאין לה צורה מתאימה. אין מסגרת ריקה ואין רווח.

## Copy

שורה אחת לכל צורה, לפי אותה תבנית: **מה רואים**, לא מה החשבון.

| צורה | כיתוב |
|---|---|
| ציר מספרים | <code>על הציר, אחרי \`12\` בא \`13\`</code> |
| קופסאות של עשר | <code>\`13\` הם קופסה מלאה של \`10\` ועוד \`3\` בודדות</code> |
| שטח | <code>מלבן באורך \`5\` וברוחב \`4\`, והשטח הוא כל מה שבפנים</code> |
| היקף | <code>מלבן באורך \`5\` וברוחב \`4\`, וההיקף הוא הדרך סביבו</code> |
| פיתגורס | <code>משולש ישר זווית שניצביו \`3\` ו-\`4\`, והיתר מולם</code> |
| אחוזים | <code>\`25%\` מתוך \`80\` הם הרבע הצבוע</code> |
| יחס | <code>\`2\` חלקים מול \`3\` חלקים, וכל חלק שווה \`5\`</code> |
| פונקציה קווית | <code>על הישר, כאשר \`x\` שווה \`3\` הנקודה נמצאת בגובה \`7\`</code> |

## Interaction Flow
זהה לעיגול השברים, בכל שבע הצורות: תשובה שגויה → הקופסה נפתחת עם הציור בראשה →
אין מה ללחוץ → ההקראה אומרת את הכיתוב לפני השלבים → "הבא" מנקה.

## Accessibility / RTL notes

### ציר המספרים עולה משמאל לימין, וזו הכרעה ולא ברירת מחדל
העמוד ימין-לשמאל, והפיתוי הוא להפוך גם את הציר. **נדחה.** ציר מספרים בכיתה א׳
בישראל מצויר משמאל לימין, וזה מה שמיקה רואה על הלוח ובחוברת. ציור שמנוגד לכיתה
שלה לא מלמד אותה מוסכמה חלופית — הוא מבלבל אותה פעמיים.

זו אותה הכרעה כמו בכל ביטוי חשבוני באפליקציה: **מבודדים, לא מכופפים.**

### שאר הכיווניות
- **`direction: ltr` על כל `<svg>` ועל כל `<text>` בתוכו.** אלמנט SVG אינו יורש
  את הרגלי הדף, וזה המקום שבו המלכודת החוזרת מתחבאת.
- **הכיתוב שמתחת הוא עברית רגילה** עם מספרים מסומנים, כמו כל טקסט אחר באפליקציה.
- מספרים על צירים ועל צלעות אינם מסתובבים עם הצורה. תווית על צלע אנכית נשארת
  אופקית.

### ההקראה
**שורה אחת מספיקה לשש מהשבע.** היוצא דופן הוא **שתי הרצועות של היחס**: משפט אחד
שמתאר שתי רצועות ואת גודל היחידה נהיה ארוך מדי למי שמקשיבה ולא רואה. הוא מפוצל
לשניים — רצועה, רצועה — ונאמר בהפסקה ביניהם, בדיוק כפי שההסבר כבר מפוצל לשלבים.

### צבע אינו נושא משמעות באף צורה
מלא מול ריק בכל מקום. במשולש הזווית הישרה מסומנת בריבוע ולא בצבע. בציר, המספר
שבשאלה והתשובה נבדלים ב**צורת הסימון** (`●` מול `★`) ולא רק בגוון.

## Acceptance Criteria Check

- הציור רק בהסבר: **yes** — כל שבע הצורות באותו מקום.
- נבנה מה-prompt ומוצג רק אם שחזר את התשובה: **yes** — כל צורה מחשבת את מה שהשאלה
  מבקשת. ציר: `12` ועוד אחד. פיתגורס: `3²+4²` ושורש. גאומטריה: הנוסחה. יחס:
  יחידה כפול חלקים. פונקציה: הצבה.
- צורה שאי אפשר לבנות מה-prompt לא נכנסת: **yes** — אין כאן כזו.
- כלל שסופר לכל נושא: **yes** — מספרי הכיסוי בטבלת הספק.
- צורה חלה רק על מה שהיא מתארת נכון: **yes** — 179 מתוך 210.
- חלופה מילולית: **yes** — כיתוב אחד, ושניים ביחס.
- ציור רשאי להסגיר את התשובה בהסבר: **yes** — הציר מסמן את התשובה ב-`★` במכוון.
- כל שלב עומד בפני עצמו: **yes** — הצורות אינן תלויות זו בזו.

## Open Questions

None.

**שלוש אזהרות שראוי שיישמעו לפני שמתחילים לבנות:**

### 1. ציר מספרים מלא לא נכנס לנייד, ולכן אינו מוצע
`0` עד `20` ב-`280` פיקסלים הם מרווח של `13` פיקסלים לסימון. הפתרון הוא חלון סביב
השאלה, וזה גם עדיף פדגוגית — אבל צריך לדעת שזה מה שנבנה, ולא לצפות לציר מלא.

### 2. פונקציה קווית היא הקשה מכולן, ולכן היא אחרונה
סקאלת הצירים משתנה מאוד בין שאלה לשאלה: `y = x + 5` ב-`x=3` מול `y = −4x + 20`
ב-`y=0`. כל צורה אחרת בנויה על מבנה קבוע; זו דורשת להחליט תחום בכל פעם מחדש.
היא גם היחידה שמשרתת את מי שקורא הכי טוב. **אם משהו מהשבע ייפול — שיהיה זה.**

### 3. שטח והיקף הן שתי צורות ולא אחת
אותו מלבן משרת שתי שאלות שונות, ואם ההבדל לא ייראה — הציור לא יסביר כלום, רק
יקשט. **ההבחנה בין מילוי לקו המקיף היא חלק מהתוכן**, לא סגנון.
