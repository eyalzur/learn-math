# ציורים לשאר הנושאים — Architecture

## Overview
גל ראשון: שתי הצורות של מיקה. שני מודולי נתונים חדשים בתבנית של `fractionDiagram.ts`
— טהורים, `import type` בלבד, נצרכים רק ממסך התרגול — ושני רכיבי SVG בתבנית של
`FractionCircle.tsx`. חמש הצורות הנותרות אינן כאן.

## Affected Files / Components

| קובץ | מה משתנה |
|---|---|
| `src/data/numberLine.ts` | **חדש.** `numberLine(question): NumberLine \| null` — חילוץ, אימות מול `answer`, חלון הסימונים, והכיתוב. |
| `src/data/tenFrame.ts` | **חדש.** `tenFrame(question): TenFrame \| null` — אותו דבר לקופסאות העשר. |
| `src/components/NumberLine.tsx` | **חדש.** SVG בלבד: ציר, סימונים, `●`, `★`, חץ. |
| `src/components/TenFrame.tsx` | **חדש.** SVG בלבד: רשת `2×5` והבודדות לצידה. |
| `src/components/Practice.tsx` | שני `figure` נוספים בקופסת ההסבר, ושני כיתובים לרצף ההקראה. |
| `src/App.css` | `.number-line`, `.ten-frame` וסגנונות השורות. |
| `tests/e2e/content.spec.ts` | שני כללים סופרים (`30` ו-`20`) ושני כללי אי-סתירה. |

**מודול נפרד לכל צורה, לא מודול משותף.** שלוש הצורות הקיימות בריפו
(`fractionDiagram`, `verticalSum`, ועכשיו אלה) חולקות *חוזה* — `(question) → shape |
null`, אימות מול `answer`, כיתוב אחד — אבל **אין להן קוד משותף**: החילוץ שונה לגמרי,
והגיאומטריה שונה לגמרי. הפשטה לשש צורות שטרם נכתבו תתאים למה שדמיינו ולא למה שיתגלה.
החוזה החוזר הוא מה ששומר על אחידות, לא מחלקת בסיס.

## Data / State Changes

```ts
export interface NumberLine {
  /** Every tick to draw, ascending. At least five. */
  ticks: number[];
  /** Marked ● — the number the question is about. */
  from: number;
  /** Marked ★ — the answer. */
  to: number;
  caption: string;
}

export interface TenFrame {
  /** How many full tens boxes — always 1 in this data, but read, not assumed. */
  tens: number;
  units: number;
  /** Which side the question asks about, and so which side is filled. */
  highlight: "tens" | "units" | "both";
  caption: string;
}
```

אין state חדש ב-`Practice`. כמו `diagram` ו-`vertical`, שניהם נגזרים מ-`question`
בכל רינדור.

## Technical Approach

### `numberLine.ts` — חמש צורות שאלה, לא ארבע
סקירת הנתונים העלתה צורה חמישית שלא הופיעה בתדריך: **`מה קטן יותר`** (`h5`–`h8`).
כל `30` השאלות מתחלקות כך, והזיהוי הוא לפי הניסוח בלבד:

| צורה | שאלות | `●` | `★` |
|---|---|---|---|
| `בא אחרי N` | 8 | `N` | `N + 1` |
| `בא לפני N` | 7 | `N` | `N − 1` |
| `מה גדול יותר, A או B` | 7 | הקטן | הגדול |
| `מה קטן יותר, A או B` | 4 | הגדול | הקטן |
| `נמצא בין A ל-B` | 4 | `A` **ו**-`B` | `A + 1` |

`מה גדול/קטן יותר` הן היחידות שבהן `●` אינו "המספר שבשאלה" אלא **המספר שלא נבחר** —
שתי האפשרויות על הציר, והתשובה מסומנת בכוכב. זה מה שהופך את הציר להסבר ולא לקישוט:
רואים למה אחד רחוק יותר.

`נמצא בין` מסמנת **שני** קצוות, ולכן `from` לבדו אינו מספיק. הפתרון: `ticks` נושא את
כל הסימונים, ומי שמסומן נקבע ב-`from`/`to`; לצורת "בין" נוסף `from` שני דרך אותו
מנגנון — **החלטה: `from` הוא `number[]`, לא `number`.** תא אחד בארבע הצורות הראשונות,
שניים בחמישית.

**האימות:** מחשבים את התשובה מהצורה ומשווים ל-`question.answer`.
`בא אחרי 12` → `13` ✓. `מה גדול יותר, 13 או 18` → `Math.max` ✓.
נכשל → `null`, ואין ציור ואין כיתוב.

**חלון הסימונים:** `lo = min(כל המסומנים) − 2`, `hi = max(...) + 2`, נחתך ל-`0..20`,
ומורחב אם יצאו פחות מ-`5`. `מה גדול יותר, 4 או 8` נותן `2..10` — תשעה סימונים, וזה
בסדר; `מה גדול יותר, 13 או 18` נותן `11..20`. **תקרה של `11` סימונים**, ומעליה
מציגים רק את הקצוות והמסומנים — אין כזה מקרה בנתונים היום, והתקרה קיימת כדי
שהוספת שאלה לא תשבור את הפריסה בשקט.

### `tenFrame.ts` — ארבע צורות, `20` מתוך `30`
| צורה | שאלות | `highlight` |
|---|---|---|
| `כמה עשרות במספר N` | 5 | `tens` |
| `כמה יחידות במספר N` | 5 | `units` |
| `עשרת אחת ועוד N יחידות` | 5 | `both` |
| `10 + N` | 5 | `both` |

**האימות:** `tens × 10 + units` חייב להיות המספר שהשאלה עוסקת בו, ובנוסף התשובה
עצמה חייבת להתאים לצורה — `כמה עשרות` מול `tens`, `כמה יחידות` מול `units`,
ושתי האחרונות מול המספר השלם. שתי בדיקות, לא אחת: הראשונה שהציור מתאר את המספר
הנכון, השנייה שהוא עונה על מה שנשאל.

**עשר השאלות שנשארות בחוץ** — `h1`–`h5` (הפרש בין ספרות) ו-`h6`–`h10` (השלמה
ל-`20`) — מחזירות `null`. קופסה אחת אינה מתארת אף אחת מהן, וזה מכוון ורשום בספק.

### רינדור — SVG לשתיהן, `280` רוחב
העיגול הוא `180` כי אין לו ציר ארוך; לשתי הצורות האלה יש, ו-`design.md` קובע `280`
עם `max-width: 100%`. שתיהן גיאומטריה — קו עם סימונים, ורשת עיגולים — ולכן SVG,
באותה תבנית בדיוק של `FractionCircle.tsx`: קבועי גודל בראש הקובץ, `role="img"`,
`aria-label` שהוא הכיתוב בלי גרשיים אחוריים.

**הכוכב** מצויר כ-`path` של עשר נקודות סביב מרכז הסימון — לא תו טקסט, שהרנדור שלו
משתנה בין מכשירים.

### הקראה
`Practice.tsx` מוסיף את שני הכיתובים לאותו מערך, בסדר התצוגה:
`[method?, diagramCaption?, verticalCaption?, numberLineCaption?, tenFrameCaption?, ...steps]`
— בפועל לעולם לא יופיעו שניים יחד, כי הם חיים בנושאים שונים. מיקה אינה קוראת;
הכיתוב הוא הערוץ שלה, ולכן הוא משפט מלא ולא רשימת מספרים.

## Edge Cases
- **`בא לפני 10`** (`h9`) → חלון `8..12`; `0` אינו חסם כאן. **`בא אחרי 19`** (`m4`)
  → `17..20`, נחתך בתקרה — ולכן יוצאים ארבעה סימונים בלבד וההרחבה ל-`5` מוסיפה
  את `16`. זה המקרה שמחייב את ההרחבה להיות **דו-כיוונית** ולא רק ימינה.
- **`מה גדול יותר, 20 או 14`** (`m10`) → `12..20`, תשעה סימונים. הרוחב מתחלק
  שווה בשווה, וסימון דו-ספרתי ב-`280` פיקסלים עם תשעה תאים הוא `31` פיקסלים לתא —
  נכנס.
- **`עשרת אחת ועוד 4 יחידות`** — המספר שהשאלה עוסקת בו הוא **התשובה** (`14`),
  לא מספר בניסוח. החילוץ חייב לקרוא `1` ו-`4` מהניסוח ולבנות `14`, ואז לאמת מולה.
- **`10 + 6`** — הצורה היחידה שהיא ביטוי חשוף, ולכן גם `verticalSum` יכול לתפוס
  אותה. שתי הצורות יופיעו יחד על אותה שאלה, וזה תקין: המאונך מראה את החיבור,
  הקופסה את מבנה המספר. **סדר התצוגה קבוע** — קופסה ואז מאונך.
- **כיווניות:** `direction: ltr` על שני ה-`<svg>` ועל כל `<text>` בתוכם. הציר עולה
  משמאל לימין בתוך העמוד העברי — הוכרע בדיון.

## Risks / Tradeoffs
- **`from: number[]`** נראה מיותר בארבע מתוך חמש הצורות, אבל צורת "בין" דורשת אותו
  והחלופה — שדה `from2` אופציונלי — הייתה מוסיפה ענף לכל צרכן.
- **הכפילות בין `numberLine.ts` ל-`tenFrame.ts`** מכוונת. הן חולקות חוזה ולא קוד,
  וזה מה שיאפשר לחמש הצורות הבאות להיכתב בלי לשבור אף אחת מהקיימות.
- **מה נשבר:** בדיקות שסופרות `.explanation-step` אינן מושפעות. בדיקות שפותחות את
  המסך של מיקה בנושא "מספרים עד 20" — `mistake-diagnosis.spec.ts` עובד שם — צריכות
  לעבור כמו שהן, כי הציור מתווסף ואינו מחליף. QA יאמת.
