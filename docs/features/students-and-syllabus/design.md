# משתמשים, סילבוס ורמות — Design

## Overview
נוסף מסך פתיחה לבחירת תלמיד/ה, ומסך הבית הקיים מוחלף במסך כיתה שמציג את הסילבוס
ואת שלוש הרמות. מסכי התרגול והתוצאה נשארים כפי שהם.

## Screens / States

### 1. מסך בחירת תלמיד/ה (חדש, מסך הפתיחה)

```
              מי לומד היום?

        ┌──────────────────────────┐
        │   מיקה                   │
        │   כיתה א׳                │
        └──────────────────────────┘
        ┌──────────────────────────┐
        │   רותם                   │
        │   כיתה ו׳                │
        └──────────────────────────┘
        ┌──────────────────────────┐
        │   עומר                   │
        │   כיתה ח׳                │
        └──────────────────────────┘
```

מוצג רק כשאין תלמיד/ה שמור. אם יש - האפליקציה נכנסת ישר למסך הכיתה.

### 2. מסך כיתה (מחליף את מסך הבית הקיים)

```
   החלף תלמיד ←                       שלום מיקה!
                     כיתה א׳

        מה לומדים בכיתה א׳
        מספרים עד 20 · חיבור עד 10 · חיסור עד 10 ·
        חיבור וחיסור עד 20 · עשרות ויחידות

              בחרו רמה כדי להתחיל

        ┌──────────────────────────┐
        │  קל            10 שאלות  │
        │  להתחלה בטוחה             │
        └──────────────────────────┘
        ┌──────────────────────────┐
        │  בינוני        10 שאלות  │
        │  כשכבר יודעים את הבסיס    │
        └──────────────────────────┘
        ┌──────────────────────────┐
        │  מתקדם         10 שאלות  │
        │  לאתגר אמיתי              │
        └──────────────────────────┘
```

הנושאים מוצגים כרשימה קריאה מופרדת בנקודות - הם מידע, לא כפתורים. לוחצים על רמה,
לא על נושא.

### 3. מסכי תרגול ותוצאה
ללא שינוי חזותי. כותרת התרגול מציגה את שם הרמה במקום שם הסט
(למשל "קל" במקום "חיבור עד 10").

## Copy

- כותרת מסך הבחירה: `מי לומד היום?`
- ברכה במסך הכיתה: `שלום {שם}!`
- כותרת הסילבוס: `מה לומדים ב{שם הכיתה}`
- הנחיה: `בחרו רמה כדי להתחיל`
- כפתור החלפה: `← החלף תלמיד`
- שמות הרמות ותיאוריהן:
  - `קל` — `להתחלה בטוחה`
  - `בינוני` — `כשכבר יודעים את הבסיס`
  - `מתקדם` — `לאתגר אמיתי`
- מונה שאלות בכרטיס רמה: `10 שאלות`
- שמות הכיתות: `כיתה א׳`, `כיתה ו׳`, `כיתה ח׳` (עם גרש, לא אות בודדת)

## Interaction Flow
1. פתיחה ראשונה → מסך בחירת תלמיד/ה. לחיצה על תלמיד/ה → מסך כיתה.
2. פתיחה חוזרת → ישירות למסך כיתה של התלמיד/ה השמור/ה.
3. במסך הכיתה: לחיצה על רמה → תרגול של עשר השאלות שלה.
4. `← החלף תלמיד` מחזיר למסך בחירת התלמיד/ה ומוחק את הבחירה השמורה.
5. `← חזרה` מהתרגול מחזיר למסך הכיתה (לא למסך בחירת התלמיד/ה).
6. בסיום רמה: מסך תוצאה, ומשם `נסו שוב` (אותה רמה) או `חזרה לתפריט` (מסך הכיתה).

## Accessibility / RTL notes
המסכים החדשים הם טקסט עברי בלבד - שמות, כיתות ונושאים - ולכן אין בהם סיכון כיווניות
חדש. שתי נקודות שכן נבדקו:

- **שמות הכיתות** נכתבים `כיתה א׳` עם גרש עברי (U+05F3), ולא `כיתה א'` עם אפוסטרוף
  לטיני, כדי שלא ייווצר ניתוק דו-כיווני באמצע מחרוזת עברית.
- **מונה השאלות** (`10 שאלות`) מערבב ספרה עם עברית. הספרה עומדת בתחילת המחרוזת ולכן
  אלגוריתם ה-bidi מציב אותה נכון בהקשר RTL, אבל בכרטיס הרמה היא מופרדת ממילא לאלמנט
  משלה בגלל הפריסה (שם הרמה בצד אחד, המונה בשני), כך שאין מחרוזת מעורבת בפועל.
- **שאלות מילוליות מחייבות טיפול חדש בכיווניות.** עד היום כל שאלה הייתה ביטוי
  חשבוני טהור, ולכן `.problem-box` יכול היה להיות `direction: ltr` באופן גורף. מעכשיו
  יש שני סוגי שאלות: ביטוי חשבוני (`3x + 5 = 20`) שחייב LTR, ושאלה מילולית בעברית
  (`כמה זה 25% מ-80?`) שחייבת RTL - אחרת סימן השאלה יקפוץ לתחילת המשפט והמשפט ייקרא
  הפוך. הכיוון נקבע לכל שאלה לפי תוכנה: שאלה שיש בה אותיות עבריות מוצגת RTL, ושאלה
  שאין בה - LTR.

## Acceptance Criteria Check
- "מסך בחירה עם שלושה תלמידים ושמותיהם וכיתותיהם": כן - מסך 1.
- "מסך עם נושאים ושלוש רמות אחרי הבחירה": כן - מסך 2.
- "בדיוק שלוש רמות לכל כיתה, עשר שאלות לכל רמה": כן - שלושה כרטיסים קבועים, וכל
  כרטיס מציג `10 שאלות`; אכיפת המספר עצמו היא עניין של הנתונים ונבדקת ב-QA.
- "כל שאלה משויכת לנושא מהסילבוס של כיתתה": כן - הסילבוס במסך 2 נגזר מאותה רשימת
  נושאים שהשאלות מפנות אליה, כך שסטייה תתגלה.
- "בחירת רמה פותחת תרגול, ובסיום מסך סיכום": כן - מסכים 3, ללא שינוי.
- "אפשר לחזור ולהחליף משתמש": כן - `← החלף תלמיד`.
- "הבחירה האחרונה נשמרת": כן - זרימה 2.
