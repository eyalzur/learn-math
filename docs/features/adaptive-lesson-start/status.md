# תרגול אדפטיבי מתחיל לפי היסטוריה, לא מאפס בכל פעם

כל נושא אדפטיבי (מיקה/רותם/עומר) יתחיל מרמת הקושי האחרונה שהתלמיד/ה הגיע/ה אליה בנושא
הזה, לא תמיד מהרמה הקלה ביותר. ביקור ראשון בנושא ממשיך להתחיל מהרמה הקלה.
