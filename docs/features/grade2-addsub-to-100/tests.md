# בדיקות

- `content.spec.ts`: המחוללים נבדקים בדרגות 1-5 בלבד, וכל תשובה/אופרנד חייבים להיות
  `<= 100` (הוחמר מ-`<= 999`).
- `grade2-syllabus.spec.ts`: "רצף תשובות נכונות מגיע לשאלה תלת-ספרתית" הוחלף ב"אף שאלה
  ברצף מלא לא חורגת מ-100" (לחיבור ולחיסור).
- `mika-grade2-content.spec.ts`: בדיקה שכל השאלות הכתובות <= 100, ובדיקה שהיסטוריה
  בשם הישן ("עד 1000") נקראת בשם החדש.
- שאר הבדיקות: שינוי שם הנושא בלבד.
