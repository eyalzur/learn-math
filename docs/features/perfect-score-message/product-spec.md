# הודעת עידוד לציון מושלם

## Summary
כשתלמיד/ה עונה נכון על כל התרגילים בתרגול (100%), מסך התוצאה מציג הודעת עידוד מיוחדת
השונה מהודעות ההצלחה הרגילות, כדי לתת תחושת הישג גדולה יותר.

## Problem / Motivation
כיום מסך התוצאה מציג את אחת משלוש הודעות קיימות לפי אחוז ההצלחה ("כדאי לתרגל עוד קצת",
"יפה מאוד, המשיכו כך!", "מצוין! שליטה מלאה!") - וההודעה ל-80%+ זהה להודעה שמופיעה גם
בציון מושלם של 100%. תלמיד/ה שהצליחו בכל התרגילים מקבלים את אותה חוויה כמו מי שטעו
פעם או פעמיים, ומפסידים את תחושת ההישג המיוחד של תשובה מושלמת.

## User Stories
- כתלמיד/ה, אני רוצה לקבל הודעה מיוחדת כשעניתי נכון על הכל, כדי להרגיש שההישג שלי
  מוכר ומיוחד יותר מסתם "עברתי".

## Acceptance Criteria
- כשכל התשובות בתרגול נכונות (100%), מסך התוצאה מציג הודעה שהטקסט שלה שונה מההודעה
  המוצגת על ציון של 80%-99%.
- כשהציון נמוך מ-100%, מסך התוצאה ממשיך להציג בדיוק את אחת משלוש ההודעות הקיימות כמו
  היום (אין שינוי בהתנהגות הקיימת).
- ההודעה המיוחדת מוצגת רק במסך התוצאה (לא במהלך התרגול עצמו).

## Out of Scope
- אין הפעם אנימציה, קונפטי נוסף, צליל, או שינוי עיצובי מעבר לטקסט ההודעה עצמה.
- אין שמירת היסטוריה של כמה פעמים הושג ציון מושלם.
