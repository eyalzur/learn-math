# הודעת עידוד לציון מושלם — Design

## Overview
מסך התוצאה מקבל הודעה רביעית, ייעודית לציון 100%, שמופיעה במקום ההודעה "מצוין! שליטה
מלאה!" הקיימת (שממשיכה לכסות רק את הטווח 80%-99%).

## Screens / States
מסך תוצאה אחד, עם ארבעה מצבים אפשריים לפי אחוז ההצלחה (במקום שלושה כיום):

```
percent < 50   → "כדאי לתרגל עוד קצת"
50 ≤ percent < 80  → "יפה מאוד, המשיכו כך!"
80 ≤ percent < 100 → "מצוין! שליטה מלאה!"
percent = 100      → "🌟 ציון מושלם! פתרת הכל נכון!"   (חדש)
```

שאר הפריסה של מסך התוצאה (הציון המספרי, כפתורי "נסו שוב" / "חזרה לתפריט") לא משתנה.

## Copy
- הודעה חדשה: `🌟 ציון מושלם! פתרת הכל נכון!`
- שלוש ההודעות הקיימות נשארות בדיוק כפי שהן: `כדאי לתרגל עוד קצת`,
  `יפה מאוד, המשיכו כך!`, `מצוין! שליטה מלאה!`

## Interaction Flow
1. תלמיד/ה מסיימים תרגול (כמו היום).
2. אם `correctCount === total`, מסך התוצאה מציג את ההודעה החדשה במקום "מצוין! שליטה
   מלאה!". בכל מקרה אחר ההתנהגות זהה להיום.
3. אין שינוי בכפתורים או בפעולות "נסו שוב"/"חזרה לתפריט".

## Accessibility / RTL notes
ההודעה החדשה היא טקסט עברי בלבד (כולל אימוג'י 🌟 בתחילתה) — אין בה מספרים או ביטויים
שצריכים להישאר LTR, כך שאין כאן סיכון לבאג הכיווניות שכבר קרה במסך התרגול (`.problem-box`
ב-`src/App.css`). האימוג'י מוצג לפני הטקסט, כמו בהודעת "נכון מאוד! 🎉" הקיימת במסך
התרגול שבה האימוג'י מופיע *אחרי* הטקסט — כאן הוא לפני, כדי להבליט את ההישג מיד; זה עקבי
מספיק מבחינת RTL כי מדובר בטקסט עברי רגיל בלי כיוון מעורב.

## Acceptance Criteria Check
- "כשכל התשובות נכונות (100%), מסך התוצאה מציג הודעה שהטקסט שלה שונה מההודעה על
  80%-99%": כן — הודעה חדשה `🌟 ציון מושלם! פתרת הכל נכון!` שונה מ-`מצוין! שליטה מלאה!`.
- "כשהציון נמוך מ-100%, שלוש ההודעות הקיימות ממשיכות ללא שינוי": כן — טווחי האחוזים
  והטקסטים של שלוש ההודעות המקוריות לא משתנים.
- "ההודעה המיוחדת מוצגת רק במסך התוצאה": כן — אין שינוי במסך התרגול (`Practice.tsx`).
