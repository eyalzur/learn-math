# ניסוח ברור לשאלות הנחה באחוזים — Tests

## Coverage
שינוי טקסט בלבד, ללא קריטריון שדורש בדיקת `e2e` ייעודית — אין התנהגות
חדשה לבדוק, רק תוכן. הכיסוי הקיים (`content.spec.ts`'s
`"has an explanation with steps and an analogy"` וכללי התוכן האחרים)
ממשיך לרוץ על ארבע השאלות ועובר, כי `answer`/`hints`/`steps`/`analogy`
לא השתנו.

**מה כן נבדק ידנית:** שכל אחת מארבע השאלות שואלת בדיוק את מה
ש-`answer` עונה עליו (המחיר המקורי `X`, הנחה `Y%`, ותשובה שמחשבת מהם
נכון) — ראו `design.md`.
