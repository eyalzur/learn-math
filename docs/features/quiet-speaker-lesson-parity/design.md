# עיצוב

- `.speak-button` אחד לכל האפליקציה: `40×40`, שקוף, בלי מסגרת/צל, אייקון `17px`, `opacity: .6`
  (מלא ב-hover/focus).
- בכרטיס השאלה: ממוקם בפינה העליונה השמאלית (`left`, פיזי — כיוון הכרטיס מתהפך לפי השאלה והרמקול
  לא אמור לקפוץ). בשאלה מילולית (RTL) נשמר ריפוד שמאלי `44px` כדי שהשורה הראשונה לא תרוץ מתחתיו.
- קופסת "איך פותרים?": אותו כפתור, בקצה הכותרת (כמו קודם), אותו סגנון.
- מסך שיעור: כותרת `practice-title` (קטנה ושקטה, כמו בתרגול); המונה "דוגמה N מתוך M" עבר לשורת
  הכותרת העליונה במקום "שאלה N מתוך M"; הרמקול עבר מעל הכרטיס אל תוך הכרטיס.
- החלטה (בלי שאלה למשתמש): הצבעים לא השתנו; רק משקל ומיקום.
