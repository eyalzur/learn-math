# כפתור הקראה שקט + שיעור שדומה לתרגול — אפיון

**משוב חי (iPhone אמיתי):** "מסך השיעור לא מספיק דומה למסך תרגול. ובמסך התרגול, מה זה המקום
הזה של הרמקול? הוא לא חלק מהשאלה, הוא צריך להיות בצד, קטן, לא אינטנסיבי."

## קריטריוני קבלה
1. הרמקול הוא אייקון קטן, בלי רקע ובלי מסגרת, בפינת כרטיס השאלה — לא עיגול ורוד ענק ליד הטקסט.
2. אזור הלחיצה נשאר לפחות 40px (מיקה, כיתה א׳, משתמשת בו).
3. אותו סגנון ואותו מיקום ב: תרגול, מסך שיעור, וקופסת "איך פותרים?".
4. מסך השיעור משתמש באותה כותרת קטנה, אותו כרטיס שאלה, ואותה שורת כותרת עליונה כמו התרגול
   ("דוגמה N מתוך M" במקום "שאלה N מתוך M").
5. אין שינוי התנהגות: הקראה, הקראה אוטומטית, חזרה לתרגול, שאלת הכיבוי — כולם כפי שהיו.
6. מסך התרגול נשאר ללא גלילה (לפי `no-scroll-screens`).

## מחוץ לתחום
שינוי תוכן, לוגיקה, או מבנה ה-hints/ההסבר.
