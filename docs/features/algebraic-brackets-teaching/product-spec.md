# פתיחת סוגריים בביטויים אלגבריים — מסבירה את התהליך והמושגים

## Summary
שאלות "פתחו סוגריים" בנושא ביטויים אלגבריים (כיתה ח׳) שואלות כרגע רק "מה המספר
החופשי?" ומראות את חישובו בבידוד. התיקון מציג את הביטוי הפתוח והמכונס במלואו
(למשל `3x + 6`), מסביר את תהליך פתיחת הסוגריים עצמו, ומגדיר במפורש את המושגים
"מקדם" ו"מספר חופשי".

## Problem / Motivation
המשתמש בדק את השאלה החיה באתר ("פתחו סוגריים: `3(x + 2)`. מה המספר החופשי?") ואמר
במפורש: "אני לא אוהב את הצורה, צריך להציג גם את 3X+6. להראות איך פתחנו סוגריים, מה
זה מס חופשי ומה זה מקדם." כרגע השאלה מסתיימת בחישוב מספר בודד בלי שהתלמיד/ה רואה
את הביטוי השלם שנוצר, ובלי שהמילים "מקדם" ו"מספר חופשי" מוגדרות בשום מקום — התלמיד/ה
אמור/ה כבר לדעת אותן כדי לענות.

זה חוזר בשני מקומות בקוד עם אותה בעיה בדיוק: המחולל האדפטיבי `openBrackets`
(`src/data/adaptiveExpressions.ts`) וארבע שאלות כתובות ברמת "medium" ב-`grade8.ts`
(`g8-expressions-m1`, `m2`, `m6`, `m7`) — שגם לא עקביות זו עם זו (חלקן מפצלות את
הכפל לשני שלבים, חלקן לא).

## User Stories
- כתלמיד/ה בכיתה ח׳ שנתקל/ת בשאלת "פתחו סוגריים", אני רוצה לראות את הביטוי הפתוח
  והמכונס במלואו (`3x + 6`, לא רק `6`), כדי להבין מה בעצם קרה לביטוי, לא רק לקבל
  מספר.
- כתלמיד/ה שלא בטוח/ה מה זה "מקדם" או "מספר חופשי", אני רוצה שההסבר יגדיר את
  המילים האלה במשפט פשוט, כדי שאוכל להבין את השאלה ולא רק לנחש מהדפוס.
- כתלמיד/ה, אני רוצה לראות בבירור את שלב הכפל שמפתח את הסוגריים (איבר-איבר), כדי
  להבין *איך* מגיעים לביטוי הפתוח ולא רק את התוצאה שלו.

## Acceptance Criteria
- בכל שאלת "פתחו סוגריים" מהדפוס `A(x + B)` (גם במחולל האדפטיבי `openBrackets`
  וגם בארבע השאלות המקבילות ב-`grade8.ts`), שלבי ההסבר מציגים את הביטוי הפתוח
  והמכונס המלא (בצורת `Ax + AB`, עם הערכים המספריים בפועל — למשל `3x + 6`), לא רק
  את המספר החופשי בבידוד.
- שלבי ההסבר מראים את שני צעדי הכפל בנפרד (כפל האיבר עם `x`, וכפל האיבר החופשי),
  כך שברור *איך* פותחים סוגריים — לא רק שהתוצאה נכונה.
- אחד הרמזים (או שלב ההסבר) מגדיר במשפט אחד מה זה "מקדם" (המספר שכופל את `x`)
  ומה זה "מספר חופשי" (המספר שאין לידו משתנה) — לא רק מחשב אותם.
- ארבע השאלות המקבילות ב-`grade8.ts` (`g8-expressions-m1`, `m2`, `m6`, `m7`)
  מתעדכנות לאותו מבנה שלבים/רמזים, ועקביות זו עם זו.
- דפוס `combineLikeTerms` (השואל "מה המקדם של `x`" בלי לפתוח סוגריים) מקבל גם הוא
  הגדרה של המילה "מקדם" באחד הרמזים שלו — כדי שהמונח יוגדר בכל מקום שבו הוא נשאל,
  לא רק בדפוס פתיחת הסוגריים.
- כל שאלה קיימת מהדפוסים האלה ממשיכה לתת את אותה תשובה נכונה כמו היום (השינוי הוא
  בהסבר/רמזים/שלבים בלבד, לא בשאלה או בתשובה).

## Out of Scope
- שינוי דפוסי אלגברה אחרים שמשתמשים במילה "מקדם" בהקשר שונה (למשל פתרון משוואות
  `Ax = B` שבהן מחלקים במקדם כדי לבודד את `x`) — שם המטרה היא לפתור משוואה, לא
  לזהות את המושג, וזה לא מה שהמשתמש הצביע עליו.
- שינוי קושי, מספר השאלות, או ה-analogy (הדימוי) של השאלות הקיימות.
- דפוס `(x + B)²` או כל דפוס אחר עם סוגריים שאינו כפל חיצוני פשוט מסוג `A(x + B)`.

## Open Questions
None. ההיקף שנבחר: הדפוס שהמשתמש הצביע עליו במפורש (`A(x + B)`, גם במחולל וגם
בכתוב) בתוספת הגדרת "מקדם" גם ב-`combineLikeTerms` (אותו מושג, אותו קובץ, תיקון
עקבי וזול-סיכון) — לא מעבר לזה.
