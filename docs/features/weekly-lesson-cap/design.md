# מכסת שיעורים שבועית — Design

## מסכים

### 1. מונה במסך הנושאים
שבב קטן ("נשארו 3 שיעורים") באותה שורה של "ההתקדמות שלי →", בצד השני. כפתור; לחיצה
פותחת את דיאלוג השיעורים (מצב מידע). כשנשאר 0 השבב מודגש בצבע אזהרה רך ("נגמרו שיעורים").
אין תוספת גובה: אותה שורה, כך שהמסך ממשיך להיכנס ב-390x664 בלי גלילה.

### 2. דיאלוג שיעורים (אחד, כמה שלבים; אותה אנטומיה כמו `SettingsDialog`)
- **שלב "הודעה"** (לילד/ה). קצר, ניתן להקראה (כפתור 🔊):
  - חסימה: "נגמרו השיעורים של השבוע." / "אפשר לבקש מאמא או אבא."
  - מידע: "נשארו 3 שיעורים השבוע."
  - כפתורים: "בקשו מההורים" ו"סגירה" (חסימה) / "עוד שיעורים (להורים)" ו"סגירה" (מידע).
- **שלב "שער הורים"**: "למבוגרים: כמה זה 7 × 8?" + שדה מספר + "המשך". תשובה שגויה:
  "לא נכון, נסו שוב" ושאלה חדשה. הביטוי החשבוני באלמנט נפרד עם `direction: ltr`.
- **שלב "חבילות"**: רשימת כרטיסים מהנתונים. כרטיס: "10 שיעורים נוספים" + "חינם כרגע"
  + כפתור "קבלו". אין שדה תשלום.
- **שלב "בוצע"**: "נוספו 10 שיעורים!" + "סגירה". הדיאלוג נסגר והמונה מתעדכן.

### חסימה בנקודות כניסה
לחיצה על "לתרגל"/רמה/סגנון/"שוב" כשנשארו 0 פותחת את דיאלוג השיעורים במצב חסימה
במקום להתחיל תרגול. אין מבוי סתום: תמיד יש "בקשו מההורים" ו"סגירה".
