# מנוי הורים — Tests

## מה נבדק
**שרת (`npm run api:test`, 12 בדיקות, בלי רשת; מעודכן 2026-11-27 לזרימת "הילד יוצר פרופיל ומקליד קוד הורים"):**
* כניסה ראשונה יוצרת משק בית עם שבוע ניסיון; כניסה שנייה מחזירה אותו.
* עד 3 ילדים; שם וכיתה מאומתים.
* קוד חיבור: פעם אחת, תקף 10 דקות, קוד שגוי נדחה; ניתוק מכשירים מבטל את האסימון.
* תרגול דורש מנוי פעיל: ניסיון ✓, אחרי שבוע ✗ (402), אחרי תשלום ✓; ביטול מסיים מיד.
* מחירים: החודש הראשון 10, אחריו 30 (מ-`pricing.ts`).
* תרגול אדפטיבי: תשובות מזיזות קושי, חזרה ממשיכה מאותו מקום, סיום כותב היסטוריה, הכניסה הבאה מתחילה מהרמה שהושגה.
* מנוי שנגמר באמצע ריצה: התשובה נשמרת, אין שאלה הבאה.
* מחיקת ילד מוחקת כל רשומה שלו; הורה זר לא רואה ילד של אחרים.
* הורה שני מצטרף בקוד; שלישי נדחה.
* HTTP מקצה לקצה (Express אמיתי, אסימוני ילד חתומים, שעון בדיקה).

**דפדפן + שרת אמיתי (`npm run test:cloud`, 7 בדיקות, סדרתי):** **שתי אפליקציות (8 בדיקות דפדפן):** שער הילדים לא מכיל שום כניסה להורים ואפליקציית ההורים לא מכילה חיבור ילד; כל אחת עם manifest משלה.

הורה מוסיף ילד ← הילד מתחבר בקוד ← מתחיל תרגול; קוד שגוי; מנוי שפג ← מסך עצירה ← תשלום מחזיר ← ביטול עוצר; מגבלת 3 ילדים; מחיקה באישור ושליחת המכשיר חזרה למסך הקוד; הורה שני.

**עדכון 2026-11-27:** 14 בדיקות שרת (כולל "paywall כבוי: ילד מקושר מתרגל תמיד" ו"התקדמות לפי נושא") ו-9 בדיקות דפדפן שרצות פעמיים (`PAYWALL=0` ו-`PAYWALL=1`; בדיקת הנעילה מדולגת כשכבוי, ובדיקת "אין מחירים" מדולגת כשדלוק).
