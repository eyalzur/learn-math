# מורה שמסבירה — Architecture

## Overview
`Question` מקבל שני שדות תוכן חדשים - `steps` כתובים ו-`analogy` - ומנוע ההסבר בוחר
בין שלבים כתובים למחושבים. אין קומפוננטה חדשה ואין תלות חדשה.

## Affected Files / Components
- **`src/data/curriculum.ts`** — `Question` מורחב ב-`steps?` ו-`analogy`; כל 90
  השאלות מקבלות תוכן.
- **`src/data/explain.ts`** — `Explanation` כולל `analogy`; `explainQuestion` מעדיף
  שלבים כתובים; נוסף `normalizeStep`.
- **`src/components/Practice.tsx`** — רינדור שורת הדימוי.
- **`src/App.css`** — `.explanation-analogy`.

## Data / State Changes
```ts
steps?: { label: string; math?: string }[];
analogy: string;
```
`analogy` הוא שדה חובה ולא אופציונלי: הקומפיילר מסרב לשאלה בלי דימוי, וזו הדרך הזולה
ביותר לאכוף קריטריון קבלה שאחרת היה נשען על זיכרון של מי שמוסיף שאלה.

## Technical Approach
`explainQuestion` מחזיר שלבים כתובים אם יש, ואחרת מנסה לחשב מהאופרנדים. הדימוי תמיד
מגיע מהשאלה - קישור לעולם המוכר הוא שיפוט אנושי ששום נוסחה לא מייצרת.

`normalizeStep` מעביר חשבון מתוך שדה הטקסט אל שדה החשבון: פיצול בנקודתיים כשהחלק
שאחריה נטול עברית, או העברה מלאה כשכל השלב הוא ביטוי. הסיבה בהמשך.

## Edge Cases
- **חשבון שנכתב בטעות בשדה הטקסט** — הבאג המרכזי כאן; ראו Implementation Notes.
- **שאלה בלי דימוי** — בלתי אפשרי, השדה חובה.
- **שלב בלי חשבון** (משפט הסבר בלבד) — `math` ריק והרינדור מדלג.

## Risks / Tradeoffs
- 90 דימויים ו-65 מערכי שלבים הם תוכן כתוב ידנית, שגדל עם כל שאלה חדשה. זה המחיר של
  הסבר שבאמת מלמד; החלופה - ייצור אוטומטי - היא בדיוק מה שהפיצ'ר הזה בא לתקן.
- `normalizeStep` הוא רשת ביטחון ולא תחליף לכתיבה נכונה; הבדיקה אוכפת את התוצאה.

## Open Questions
None.

## Implementation Notes
כל 90 השאלות קיבלו דימוי ו-65 מהן קיבלו שלבים כתובים. אומת: 90/90 עם הסבר ודימוי,
וכל הסבר מסתיים בתשובה של השאלה.

**הבאג המרכזי: חשבון בשדה הלא נכון.** רק `math` מרונדר באלמנט מבודד LTR. כשכתבתי
`20 ÷ 2 = 10` בתוך `label`, הוא הוצג `10 = 2 ÷ 20`. 96 שלבים נכתבו כך.

התיקון בשתי רמות: `normalizeStep` מעביר אוטומטית חשבון מ-`label` ל-`math`, ו-13
משפטים מעורבים (עברית וחשבון שזורים) פוצלו ידנית לשלבים נפרדים. הרמה האוטומטית חשובה
כי היא מגינה גם על שאלות שיתווספו בעתיד - להסתמך על כך שמי שכותב שאלה יזכור באיזה
שדה להשתמש זה בדיוק מה שנשכח.

**שלושה הסברים לא הסתיימו בתשובה** (`√81` נגמר ב-"9 × 9 = 81"), ותוקנו בשלב מסכם.
