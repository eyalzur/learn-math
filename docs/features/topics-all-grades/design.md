# בחירת נושא לכיתות ו׳ ו-ח׳ — Design

## Overview
**אין מסך חדש ואין אלמנט חדש.** מסכי בחירת הנושא והרמה כבר קיימים ומעוצבים מאז
`topics-and-progress`; הפיצ'ר הזה מפנה אליהם שתי כיתות נוספות. העבודה העיצובית
כאן היא לאמת שהעיצוב הקיים מחזיק תוכן ארוך ושישה נושאים — ולהחליט מה **לא**
להוסיף.

## Screens / States

### מסך הנושאים — ללא שינוי מבני

```
┌────────────────────────────────────────┐
│                     ההיסטוריה שלי ←    │
│                                        │
│                          מה נתרגל?     │
│                                        │
│  ┌──────────────┐  ┌──────────────┐   │
│  │ משוואות      │  │ ביטויים      │   │
│  │              │  │ אלגבריים     │   │
│  └──────────────┘  └──────────────┘   │
│  ┌──────────────┐  ┌──────────────┐   │
│  │ משפט פיתגורס │  │ חזקות ושורשים│   │
│  └──────────────┘  └──────────────┘   │
│  ┌──────────────┐  ┌──────────────┐   │
│  │ בעיות מילוליות│ │ פונקציה קווית│   │
│  └──────────────┘  └──────────────┘   │
└────────────────────────────────────────┘
```

**נבדק בדפדפן, לא הונח** — הגריד הקיים
(`repeat(auto-fit, minmax(200px, 1fr))`) עם שישה כרטיסים ועם שמות הנושאים
הארוכים ביותר של כיתה ח׳:

| רוחב מסך | פריסה | גלישת טקסט |
|---|---|---|
| 390px (טלפון) | 6 שורות, כרטיס בשורה | אין |
| 768px (טאבלט) | 2 שורות × 3 | אין |
| 1280px (מחשב) | 2 שורות × 3 | אין |

שישה כרטיסים מסתדרים ל-3×2 — פריסה **נקייה יותר** מחמשת הכרטיסים של כיתה א׳,
שמשאירים שורה שנייה חסרה. `ביטויים אלגבריים` נשבר לשתי שורות בתוך הכרטיס ומיושר
לימין כרגיל. **אין שינוי CSS נדרש.**

### מסך הרמות — ללא שינוי
שלוש הרמות (`קל` / `בינוני` / `מתקדם`) והתיאורים שלהן גנריים ולא תלויי כיתה.

### מסך התרגול — ללא שינוי מבני, דרישה אחת
שורת ההתקדמות מציגה `שאלה 3 מתוך 5` בכיתות ו׳/ח׳ ו-`שאלה 3 מתוך 10` בכיתה א׳.
**המספר חייב לנבוע ממספר השאלות בפועל ולא מקבוע.** זו הנקודה היחידה במסך שבה
ההבדל בין הכיתות בא לידי ביטוי, וזה מספיק.

## Copy
**אין מחרוזת חדשה ואין מחרוזת שמשתנה.** `מה נתרגל?`, `ההיסטוריה שלי ←`,
`← החלף תלמיד`, שמות הרמות ושורת ההתקדמות — כולם קיימים ונשארים כלשונם.

שמות הנושאים עצמם מגיעים מהסילבוס שכבר מוגדר לכל כיתה ואינם מנוסחים מחדש כאן.

## Interaction Flow
זהה לכיתה א׳, ללא יוצא מן הכלל:

1. בחירת תלמיד/ה → מסך הנושאים של הכיתה.
2. בחירת נושא → מסך שלוש הרמות של אותו נושא.
3. בחירת רמה → תרגול (חמש שאלות בו׳/ח׳, עשר בא׳).
4. סיום → מסך סיכום עם הציון.
5. `←` בכל שלב חוזר צעד אחד אחורה.

**מה שמשתנה עבור רותם ועומר:** צעד 1 הוביל עד היום ישירות למסך הרמות. עכשיו הוא
מוביל לנושאים, ומסך הרמות נדחה לצעד 2.

## החלטה: לא מוסיפים מונה שאלות לכרטיס — **לא**

עלתה השאלה אם התלמיד/ה צריכים לדעת מראש שמחכות להם חמש שאלות ולא עשר. **לא
מוסיפים.**

ב-PR #5 הוסר מונה הרמות מכרטיס הנושא, מהנימוק שכל חמשת הכרטיסים אמרו "3 רמות" —
מידע שזהה בכל האפשרויות אינו יכול לעזור לבחור ביניהן, ולכן הוא רעש בלבד.

**אותו נימוק בדיוק חל כאן.** כל ששת הנושאים של כיתה ח׳ יובילו לחמש שאלות. תווית
`5 שאלות` על כל כרטיס תופיע שש פעמים באותו מסך ולא תעזור לבחור באף אחד מהם. ההבדל
הוא בין **כיתות**, ותלמיד רואה רק את הכיתה שלו — כלומר ההבדל אינו נראה לו לעולם.

המידע כן מגיע, במקום שבו הוא הופך למועיל: `שאלה 1 מתוך 5` במסך התרגול. שם הוא עונה
על "כמה נשאר לי", וזו שאלה שבאמת נשאלת.

## Accessibility / RTL notes

**זו הנקודה המסוכנת בפיצ'ר הזה, והיא בתוכן ולא בעיצוב.**

כיתה ח׳ מביאה ביטויים אלגבריים אל תוך משפטים עבריים — בדיוק הצירוף ששבר את
האפליקציה בעבר: `פתחו סוגריים: 3(x + 2)` הוצג כ-`3)2 + x(`, עם סוגריים הפוכים
ואיברים בסדר שגוי.

**הדרישה, ברמת הנתונים:** כל ביטוי חשבוני או אלגברי שיושב בתוך משפט עברי חייב
להיות **מסומן בגרשיים אחוריים בטקסט השאלה**, כך שהוא ירונדר כאלמנט מבודד משלו
ולא כחלק מהמשפט. מי שכותב שאלה ושוכח את הסימון מייצר את הבאג מחדש.

| כתיבה נכונה | כתיבה שמייצרת את הבאג |
|---|---|
| ``פתחו סוגריים: `3(x + 2)`. מה המספר החופשי?`` | `פתחו סוגריים: 3(x + 2). מה המספר החופשי?` |
| ``אם `x = 4`, כמה זה `2x + 1`?`` | `אם x = 4, כמה זה 2x + 1?` |

זה חל על **שאלות, שלבי פתרון ודימויים כאחד** — כל טקסט שמוצג.

**מה שנבדק בנוסף:**
- שמות הנושאים הם עברית טהורה בלי ספרות ובלי סימנים, ולכן אין להם בעיית כיוון.
- כרטיסי הנושא הם `text-align: right` — נכון לעברית ונשאר.
- שורת ההתקדמות (`שאלה 3 מתוך 5`) מערבבת עברית וספרות, אבל ספרה בודדת בתוך משפט
  עברי היא רצף מספרי יחיד ואינה מתהפכת. היא כבר מוצגת כך היום לכיתה א׳ בלי בעיה,
  ומספר חד-ספרתי אינו מסוכן יותר מדו-ספרתי.
- כפתורי החזרה משתמשים ב-`←` שכבר נבחר נכון לכיוון העברי.

## Acceptance Criteria Check
- "הנושאים מוצגים ככפתורים לבחירה": **כן** — מסך הנושאים הקיים.
- "שישה נושאים לכל אחת מהכיתות": **כן**, ונבדק בדפדפן שהגריד מחזיק שישה.
- "שלוש רמות לכל נושא": **כן** — מסך הרמות הקיים, ללא שינוי.
- "חמש שאלות בכל רמה בו׳/ח׳": **כן** מבחינת תצוגה — שורת ההתקדמות נגזרת ממספר
  השאלות בפועל.
- "כל שלוש הכיתות באותו מסלול ניווט": **כן** — זרימה 1-5, בלי יוצא מן הכלל.
- "כל שאלה משויכת לנושא שהיא יושבת בו": **לא עניין עיצובי** — זו נכונות תוכן,
  ונבדקת ב-QA.
- "שלבים ודימוי לכל שאלה": **כן** — בלוק ההסבר הקיים מציג אותם כמו בכל שאלה
  אחרת. אין הבדל עיצובי בין כיתה לכיתה.
- "הדימויים שונים זה מזה ומותאמים לגיל": **לא עניין עיצובי** — תוכן.
- "כיתה א׳ ממשיכה עם עשר שאלות": **כן** — אין שינוי במסכיה.
- "ההיסטוריה רושמת נושא, רמה וציון": **כן** — מסך ההיסטוריה הקיים כבר מציג
  נושא, והוא היה ריק מנושא עבור ו׳/ח׳ רק מפני שלא היה להם נושא לרשום.
