# כרטיס סגנון — רק כותרת — Design

## Overview
כרטיס `.style-card` מצטמצם לשורה אחת: הכותרת. שום דבר אחר משתנה במסך — אותו
`grid`, אותו כפתור הקראה בצד, אותה התנהגות לחיצה.

## Screens / States

### לפני
```
┌─────────────────────────────┐
│           מה בא אחרי          │
│  איזה מספר בא אחרי 3?         │  ← הוסר
│           8 שאלות              │  ← הוסר
└─────────────────────────────┘
```

### אחרי
```
┌─────────────────────────────┐
│           מה בא אחרי          │
└─────────────────────────────┘
```

הכרטיס נמוך יותר; שום דבר אחר בפריסת ה-grid לא זז.

## Copy
אין שינוי בטקסט — רק הסרה של שתי השורות.

## Interaction Flow
זהה לגמרי להיום: לחיצה על הכרטיס פותחת את השיעור. כפתור ההקראה (העגול, ליד
הכרטיס) ממשיך להקריא את `style.example.prompt` בלחיצה — הוא לא היה תלוי
בטקסט המוצג על הכרטיס גם קודם, אלא בנתון עצמו.

## Accessibility / RTL notes
אין שינוי כיווניות — כל מה שהוסר היה הביטוי החשבוני שהצריך בידוד LTR מלכתחילה
(`style-example-math`), כך שהסיכון שהמלכודת הזו חוזרת פשוט נעלם עם השורה.

## Acceptance Criteria Check
- כותרת בלבד: **yes**.
- לחיצה פותחת שיעור: **yes**, לא נגעו בהתנהגות.
- הקראה ממשיכה לעבוד: **yes**, `onSpeak` ו-`aria-label` נשארים כפי שהיו.
