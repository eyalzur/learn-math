# כרטיס סגנון — רק כותרת

## Summary
כרטיס בחירת סגנון (`StylePicker`) מציג מעכשיו רק את שם הסגנון — בלי שורת הדוגמה
ובלי מונה השאלות שהיו עליו עד היום.

## Problem / Motivation
המשתמש ביקש ישירות, מול צילום מסך של המסך החי: "אני רוצה רק את הכותרות, בלי
דוגמה ובלי כמות שאלות". כרטיסי הסגנון (`מה בא אחרי`, `מה בא לפני`, `מה גדול
יותר`...) הרגישו עמוסים עם שלוש שורות טקסט לכל סגנון.

**מתח מול החלטה קודמת, ונרשם כאן כדי שלא ייעלם:** `style-lessons/design.md`
קבע במפורש שהדוגמה **היא** התווית — "מיקה בת שבע ועדיין לומדת לקרוא... כרטיס
נושא שאלה אמיתית מהסגנון, וזו התווית: שאלה נראית אחרת משאלה אחרת הרבה לפני
שאפשר לקרוא אותה". ההסרה מבטלת בדיוק את העוגן הזה. המשתמש הוא מי שרואה בפועל
איך מיקה משתמשת במסך, ונתן את ההוראה פעמיים ובאופן חד-משמעי מול תמונה אמיתית
— ולכן זו הכרעה שמכבדים, לא מנחשים מחדש. אם שמות הסגנונות הקצרים (`מה בא
אחרי`) מתגלים כלא מספיקים לה בפועל, זו תצפית שתחזור.

## User Stories
- כמשתמש שרואה את המסך החי, אני רוצה כרטיס נקי עם כותרת בלבד, כדי שהמסך יהיה
  פחות עמוס.

## Acceptance Criteria
- כרטיס סגנון מציג את `style.title` בלבד. אין שורת דוגמה, אין מונה שאלות.
- לחיצה על הכרטיס עדיין פותחת את השיעור, ללא שינוי.
- כפתור ההקראה שליד הכרטיס (כשקיים) ממשיך להקריא את שאלת הדוגמה בקול — ההסרה
  היא מהתצוגה בלבד, לא מהיכולת לשמוע אותה.
- אין שינוי בשום נושא אחר או במסך אחר.

## Out of Scope
- שינוי בנתוני הסגנונות (`style.ts`) — `example` נשאר קיים ונדרש, כי ההקראה
  עדיין משתמשת בו.
- כל תוכן חדש או שינוי בשמות הסגנונות עצמם.
