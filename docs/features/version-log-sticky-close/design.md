# לוג גרסאות — כפתור-חזרה קבוע על המסך — Design

## Overview
דיאלוג לוג-הגרסאות הופך משני-אזורים-שגוללים-ביחד לשלושה-אזורים-מסודרים
אנכית בתוך קופסה בגובה קבוע: כותרת (קבועה), רשימת-גרסאות (גוללת, תופסת את
השטח הנותר), וכפתור-סגירה (קבוע, תמיד בתחתית הדיאלוג). שום שינוי בעיצוב-
הכרטיסים/הטקסט עצמם — רק מבנה-הפריסה.

## Screens / States
דיאלוג לוג-הגרסאות הקיים (נפתח בלחיצה על מספר-הגרסה במסך הבית):

```
┌──────────────────────────────────┐
│ מה היה בכל גרסה                   │ ← כותרת, קבועה
├──────────────────────────────────┤
│ 🎯 1.52.0 (היום)            ▲    │
│    ...תיאור...              │    │
│ 💡 1.51.1                   │    │ ← רשימה, גוללת
│    ...תיאור...              │    │   (רק האזור הזה)
│ 🎯 1.51.0                   ▼    │
├──────────────────────────────────┤
│            [ סגירה ]              │ ← קבוע, תמיד כאן
└──────────────────────────────────┘
```

הכותרת ("מה היה בכל גרסה") נשארת למעלה ואינה נעלמת, אבל אינה "דביקה" במובן
שמצריך הקפדה מיוחדת — היא פשוט מחוץ לאזור-הגלילה, כמו כפתור-הסגירה. שני
האזורים הקבועים (כותרת למעלה, כפתור למטה) "סוגרים" את אזור-הגלילה בין
השניים.

## Copy
אין טקסט חדש — "מה היה בכל גרסה" ו"סגירה" נשארים בדיוק כפי שהם.

## Interaction Flow
1. המשתמש/ת פותח/ת את הדיאלוג כמו היום (לחיצה על מספר-הגרסה).
2. אם הרשימה ארוכה מגובה-הדיאלוג, מופיעה גלילה **בתוך אזור-הרשימה בלבד**
   (לא בדיאלוג כולו) — אותה גלילה-כלואה שכבר קיימת (`overscroll-behavior:
   contain`), רק ממוקדת לאזור הצר יותר.
3. כפתור "סגירה" נשאר באותו מקום פיזי על המסך לאורך כל הגלילה — לחיצה עליו
   (מכל נקודת-גלילה) סוגרת את הדיאלוג, בדיוק כמו היום.

## Accessibility / RTL notes
אין תוכן מספרי/LTR חדש כאן — הגרסאות (`1.52.0` וכו') כבר מוצגות היום בלי
בעיית-כיוון, וממשיכות באותה צורה. מבנה ה-`role="dialog"`/`aria-modal`/
`aria-labelledby` הקיים נשאר ללא שינוי.

## Acceptance Criteria Check
- כפתור-החזרה נשאר גלוי במקום קבוע בכל מצב-גלילה: yes — הוא מחוץ לאזור-
  הגלילה לגמרי, לא "דביק" בתוכו.
- רשימת-הגרסאות ממשיכה לתמוך בגלילה, מוגבלת לאזורה בלבד: yes.
- הכותרת נשארת גלויה: yes — גם היא מחוץ לאזור-הגלילה.
- שום שינוי בתוכן/ניסוח/מבנה-הנתונים: yes — Design הזה לא נוגע ב-`VersionLog.tsx`'s
  מיפוי-הנתונים, רק במבנה-ה-JSX/CSS סביבו.
- הגלילה-הכלואה נשארת: yes — `overscroll-behavior: contain` עובר לאזור-
  הרשימה (זה כבר המקום שבו זה היה צריך להיות מההתחלה, מבחינה טכנית).
