# סטטוס ריוויו — Design

## Overview
כרטיס נושא שלא נבדק מוצג מעומעם, לא לחיץ, ועם התווית `בקרוב` מתחת לשם. כשכל
הכיתה חסומה מופיעה מעל הכרטיסים שורה שמסבירה למה.

## Screens / States

### מסך נושאים מעורב — חלק בדוק וחלק לא
```
┌──────────────────────────────────────┐
│                    ההיסטוריה שלי ←   │
│                        מה נתרגל?     │
│  ┌───────────────┐ ┌───────────────┐ │
│  │ חיבור עד 10   │ │ מספרים עד 20  │ │  ← רגילים
│  └───────────────┘ └───────────────┘ │
│  ┌───────────────┐ ┌───────────────┐ │
│  │ אחוזים        │ │ שברים פשוטים  │ │  ← מעומעמים
│  │ בקרוב         │ │ בקרוב         │ │
│  └───────────────┘ └───────────────┘ │
└──────────────────────────────────────┘
```

**כרטיס חסום:** שקיפות `0.45`, בלי מסגרת שמתחלפת ב-hover, סמן `not-allowed`,
ותווית `בקרוב` בגודל 13px מתחת לשם.

### מסך של כיתה שכולה חסומה — המצב של רותם ועומר
```
┌──────────────────────────────────────┐
│                    ההיסטוריה שלי ←   │
│                        מה נתרגל?     │
│  ┌────────────────────────────────┐  │
│  │ עוד מעט! מכינים כאן תרגילים    │  │  ← הסבר, לא כרטיס
│  │ חדשים. בינתיים אפשר להסתכל     │  │
│  │ בהיסטוריה.                     │  │
│  └────────────────────────────────┘  │
│  ┌───────────────┐ ┌───────────────┐ │
│  │ שברים פשוטים  │ │ אחוזים        │ │  ← כולם מעומעמים
│  │ בקרוב         │ │ בקרוב         │ │
│  └───────────────┘ └───────────────┘ │
└──────────────────────────────────────┘
```

הכרטיסים **נשארים מוצגים** גם כאן. הם אומרים לילד מה מחכה לו, ולמי שכותב — מה
נשאר לעבור עליו. מסך עם הודעה בלבד היה מוחק את שתי המטרות.

## Copy

| מחרוזת | היכן |
|---|---|
| `בקרוב` | על כרטיס נושא שלא נבדק |
| `עוד מעט! מכינים כאן תרגילים חדשים. בינתיים אפשר להסתכל בהיסטוריה.` | מעל הכרטיסים, כשכל הנושאים חסומים |

**`בקרוב` ולא `לא זמין` ולא `נעול`.** מילדה בת שבע מבקשים כאן להבין למה משהו לא
נפתח. `נעול` אומר "אסור לך" — כאילו היא עשתה משהו. `לא זמין` היא מילה של מבוגרים.
`בקרוב` היא הדבר היחיד מהשלושה שגם נכון וגם לא מאשים.

**וזו גם האמת.** התוכן קיים ומחכה לבדיקה; הוא באמת ייפתח.

**הודעת הכיתה החסומה מפנה להיסטוריה** כי זה הדבר היחיד שכן פתוח באותו מסך. הודעה
שאומרת רק "אין כלום" משאירה ילד עם מסך מת.

## Interaction Flow
1. התלמיד/ה בוחר/ת את עצמו/ה → מסך הנושאים.
2. נושא בדוק → לחיצה עובדת בדיוק כמו היום, ומובילה למסך הרמות.
3. נושא חסום → **לחיצה לא עושה כלום.** אין מעבר, אין הודעה קופצת, אין רטט. כרטיס
   שלא מגיב הוא ההודעה.
4. כשכל הנושאים חסומים → ההסבר מופיע מעל הכרטיסים, וקישור ההיסטוריה נשאר פעיל.

**אין דיאלוג "הנושא הזה עדיין לא מוכן".** ילדה שלוחצת שוב ושוב על משהו שלא נפתח
מבינה תוך שתי לחיצות; חלון שצריך לסגור הופך את זה למטלה.

## Accessibility / RTL notes
- **הכרטיס החסום חייב להיות `disabled` אמיתי ולא רק מעומעם.** הוא כבר `button`,
  ולכן זה גם מוציא אותו ממסלול ה-Tab וגם מוכרז על ידי קורא מסך כלא-זמין. עמעום
  לבדו מותיר אותו לחיץ במקלדת — כלומר "חסום" שאפשר לעקוף.
- **התווית `בקרוב` היא טקסט ולא צבע.** מי שלא מבחין בשקיפות עדיין מקבל את המידע.
  זו הסיבה שהיא לא רק אפקט חזותי.
- **ניגודיות:** בשקיפות `0.45` הכרטיס החסום יורד מתחת ליחס הניגודיות המומלץ. זה
  מקובל **רק** מפני שהוא לא ניתן להפעלה ואינו נושא מידע שקיים רק בו — שם הנושא
  יופיע שוב כשייפתח. אילו היה כפתור פעיל, זה לא היה מקובל.
- **אין תוכן LTR חדש.** `בקרוב` וההודעה הן עברית בלבד, בלי ספרות ובלי סימנים,
  ולכן אין כאן בעיית כיוון. נבדק במפורש: לא הוספתי מספרים לשום מחרוזת חדשה.
- הכרטיסים נשארים `text-align: right` כמו היום.

## על החשש מהחזרת רעש לכרטיס
ב-PR #5 הוסר מונה הרמות מכרטיס הנושא, בנימוק שכל הכרטיסים אמרו "3 רמות" — מידע
זהה בכל האפשרויות לא עוזר לבחור ביניהן.

**`בקרוב` שונה מהותית, ולא במקרה:** היא מופיעה על **חלק** מהכרטיסים בלבד, וזה
בדיוק מה שהופך אותה למידע. היא גם התווית היחידה שנוספת, ורק במצב אחד.

**המבחן שהיא צריכה לעבור:** ברגע שכל הנושאים של כיתה ייבדקו, התווית תיעלם מכל
הכרטיסים שלה ומסך הנושאים יחזור להיות בדיוק כמו היום. תווית שנשארת כשהיא כבר לא
מבדילה בין כלום — היא בדיוק אותו רעש שהוסר. כאן זה מובטח מעצם ההגדרה.

## Acceptance Criteria Check
- "נושא לא נבדק מוצג, מעומעם ולא לחיץ": **כן** — מצב ראשון.
- "לחיצה לא עושה דבר": **כן** — זרימה 3, והכרטיס `disabled` ולא רק מעומעם.
- "טקסט קצר שילד/ה בן שבע מבינים": **כן** — `בקרוב`.
- "נושא בדוק מתנהג כמו היום": **כן** — אין שינוי בכרטיס רגיל.
- "כיתה שכולה חסומה מציגה הסבר ולא מסך תקול": **כן** — מצב שני, עם הפניה
  להיסטוריה שהיא הדבר היחיד שפתוח שם.
- "ההיסטוריה נשמרת ומוצגת": **כן** — קישור ההיסטוריה נשאר פעיל, ומסך ההיסטוריה
  לא משתנה כלל.
- "מצב הפתיחה: א׳ בדוק, ו׳/ח׳ לא": **לא עניין עיצובי** — נתונים.
- "דף הסקירה מציג סטטוס": **לא עניין עיצובי** — כלי עבודה מחוץ למוצר.
