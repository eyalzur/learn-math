# הגדרת מהירות כפתורי הניווט במחברת — Design

## Overview
בדיאלוג ⚙️ הקיים (`TopicPicker.tsx`), מתחת לבורר עוצמת זום-ההחזקה, מופיע בורר
שלישי באותה אנטומיה בדיוק: אייקון+כותרת+תת-כותרת מעל שורת שישה כפתורים (כבוי
+ חמש דרגות), עם מצב-נבחר מודגש. אין מסך חדש, אין שינוי במיקום כפתור ⚙️.

## Screens / States
תוך `.settings-dialog` הקיים, תחת `.hold-zoom-setting`, בלוק חדש
`.pan-speed-setting` עם אותה בנייה פנימית:

```
⚙️ הגדרות
┌─────────────────────────────────────┐
│ 🔊  להקריא את השאלות בקול      [○──]│
├─────────────────────────────────────┤
│ 🔍  התקרבות כשמחזיקים את האצבע       │
│     כמה הדף מתקרב כשעוצרים לרגע...   │
│     [כבוי] [מעט מאוד] [מעט] [בינוני] │
│     [הרבה] [הרבה מאוד]               │
├─────────────────────────────────────┤
│ 🧭  מהירות הזזת התצוגה              │  ← חדש
│     כמה רחוק זזים כפתורי הכיוון,     │
│     וכמה מהר ממשיכים כשמחזיקים       │
│     [כבוי] [אטי מאוד] [אטי] [בינוני] │
│     [מהיר] [מהיר מאוד]               │
├─────────────────────────────────────┤
│              [סגירה]                 │
└─────────────────────────────────────┘
```

`showPanSpeed` נגזר בדיוק כמו `showHoldZoom` — `panSpeedLevel !== undefined &&
onPanSpeedLevelChange !== undefined` (מופיע רק כשיש תלמיד/ה נבחר/ת). `showSettings`
מתעדכן לאיחוד של שלושתם: `showReadAloud || showHoldZoom || showPanSpeed`.

מצב הרשימה הסגורה: שורת שישה כפתורים, "כבוי" ראשון ואז חמש הדרגות עולות, בדיוק
כמו `HOLD_ZOOM_LEVELS`. ברוחב צר (טלפון) השורה **עוברת לשורה שנייה**, לא גוללת
לרוחב — זהה להתנהגות הקיימת של `.hold-zoom-options` (אין צורך בשינוי CSS,
הכלל הכללי שחל שם חל גם כאן כי זה אותה class pattern).

## Copy
- כותרת הבלוק: `מהירות הזזת התצוגה`
- תת-כותרת: `כמה רחוק זזים כפתורי הכיוון, וכמה מהר ממשיכים כשמחזיקים`
- אייקון: 🧭 (מצפן — שונה מ-🔍 של זום-ההחזקה, מ-🔊 של ההקראה, ולא מתנגש עם
  האייקון שה-PR הלא-ממוזג `notebook-auto-scroll` שומר לעצמו)
- שש תוויות הכפתורים, בסדר עולה: `כבוי` · `אטי מאוד` · `אטי` · `בינוני` ·
  `מהיר` · `מהיר מאוד`
- `aria-label` של קבוצת הכפתורים: `מהירות הזזת התצוגה` (תואם את הכותרת, בדיוק
  כמו שה-`aria-label` של `hold-zoom-options` תואם את הכותרת שלו)

## Interaction Flow
1. המבוגר/ת פותח/ת ⚙️ → רואה את שני הבוררים הקיימים ואת הבורר השלישי מתחתיהם.
2. לוחצ/ת על אחת משש האפשרויות → `onPanSpeedLevelChange(level.id)` נקרא
   מיידית, הכפתור הנבחר מודגש (`aria-pressed`), שום דבר אחר בדיאלוג לא משתנה,
   הדיאלוג לא נסגר.
3. סגירה בכפתור "סגירה" או בלחיצה על הרקע המעומעם — זהה לקיים.
4. בחירת "כבוי": כפתורי הכיוון במחברת ממשיכים לעבוד בהקשה בודדת כרגיל; החזקת
   כפתור לחוצה כבר לא מתחילה לגלול לבד אחרי `PAN_HOLD_DELAY_MS` — פשוט לא קורה
   כלום נוסף מעבר לצעד שההקשה הראשונה כבר ביצעה.
5. בחירת כל דרגה אחרת: גם צעד ההקשה הבודדת וגם קצב ההחזקה-לגלילה-רציפה
   מתעדכנים יחד לערכים התואמים לאותה דרגה (הערכים המדויקים — ל-tech-lead).

## Accessibility / RTL notes
אין כאן טקסט חשבוני או תוכן LTR מובנה — כל התוכן בבלוק הזה הוא עברית טהורה
(כותרת, תת-כותרת, שש התוויות), בניגוד לדף המחברת עצמו. שורת הכפתורים היא
`role="group"` עם `aria-label`, בדיוק כמו `hold-zoom-options` — אין צורך
בטיפול כיווניות מיוחד כי זו שורת כפתורים רגילה בעברית מימין לשמאל, לא ביטוי
מספרי. כל כפתור נגיש במקלדת (`<button type="button">` רגיל, `aria-pressed`
מדווח את המצב הנבחר לקורא מסך) — אותו דפוס בדיוק שכפתורי זום-ההחזקה כבר
עוברים.

## Acceptance Criteria Check
- בורר אחד, רשימה סגורה, שש אפשרויות: yes — בלוק אחד, שישה כפתורים, אין סליידר.
- משפיע גם על הקשה וגם על החזקה יחד: yes — ערך אחד (`level.id`) ששני הקבועים
  (`PAN_STEP_PX`, `PAN_HOLD_INTERVAL_MS`) ייגזרו ממנו ב-architecture.md, לא שני
  בוררים.
- "כבוי" מבטל רק את ההחזקה, לא את הכפתורים: yes — מתועד במפורש בזרימה (סעיף 4)
  כשומר על הקשה בודדת.
- הדרגות עולות בסדר מונוטוני: yes — אותו סדר ויזואלי כמו `HOLD_ZOOM_LEVELS`.
- ברירת המחדל היא הדרגה האמצעית: partial בכוונה — זו החלטת נתונים
  (`DEFAULT_PAN_SPEED_LEVEL`), לא עניין עיצובי; ל-tech-lead לקבוע את ה-id
  המדויק ("בינוני").
- נשמר בין סשנים, per-student, נכנס לתוקף מיד: yes — אותו מסלול props בדיוק
  כמו `holdZoomLevel`/`onHoldZoomLevelChange` (App.tsx מחזיק את הערך השמור,
  TopicPicker רק מציג ומדווח).
- לא בדרך של הילד/ה: yes — נגיש רק דרך ⚙️ הקיים, שום שינוי במסך התרגול עצמו.
- כפתורי הניווט עצמם לא משתנים: yes — הדיזיין הזה נוגע רק בדיאלוג ⚙️.
