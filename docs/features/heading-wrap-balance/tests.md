# כותרות שנשברות בצורה מאוזנת — Tests

## Coverage

| קריטריון קבלה (product-spec.md) | בדיקה |
|---|---|
| המקרה שדווח נפתר בפועל (מסך בחירת הכיתה) | `tests/e2e/heading-wrap-balance.spec.ts` › `the grade picker's heading balances — the reported case` |
| חל על כל שבעת ה-`h1` הראשיים | שבע הבדיקות בקובץ, אחת לכל מסך: בחירת תלמיד/ה, בחירת כיתה, בחירת נושא, בחירת רמה, בחירת סגנון, מסך תוצאה, מסך היסטוריה |
| שום טקסט לא משתנה | כל בדיקה מוודאת גם את הטקסט הקיים (`toContainText`) לצד `text-wrap: balance` — טקסט שהשתנה בטעות היה מפיל את הבדיקה |

**מה לא נבדק, ולמה:** "האם מילה בודדת נשארת תלויה בפועל" הוא בדיקה ברמת פיקסלים
שתלויה ברינדור גופנים מדויק של הסביבה — לא אמינה ב-CI. הבדיקה במקום זה מוודאת
ש-`getComputedStyle(h1).textWrap === "balance"` בפועל בדפדפן האמיתי, שזו הבדיקה
הישירה של התיקון עצמו (התנהגות הדפדפן משם והלאה כבר לא קוד שהאפליקציה כותבת).
אימות ויזואלי חד-פעמי (צילום מסך ברוחב `390px`, לפני/אחרי) בוצע בשלב הפיתוח —
ראו `architecture.md`, Implementation Notes.
