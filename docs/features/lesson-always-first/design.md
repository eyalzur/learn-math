# השיעור הוא הכניסה הדיפולטיבית לנושא — Design

## Overview
שורת-הכותרת הקיימת של מסך השיעור (`TopicLesson.tsx`, "← חזרה" + שם-הכיתה)
מקבלת שכנה חדשה: קישור-דילוג "דלג לתרגול →", צמוד ל"← חזרה" באותה שורה,
קיים וזהה בכל עמוד (לא רק בראשון/אחרון). כרטיס-הנושא עצמו (`TopicPicker.tsx`)
מאבד את כפתור-ה-📖 הנפרד; הקליק על הכרטיס כולו מוביל עכשיו ישר לשיעור.

## Screens / States
מסך השיעור הקיים, שורת-הכותרת:
```
← חזרה                    דלג לתרגול →          כיתה א׳
                        חיבור עד 10
```
(RTL: "← חזרה" ו"דלג לתרגול →" באותו אשכול בצד ימין של השורה, קרובים זה לזה
— שתי פעולות-יציאה-מהשיעור, אחת אחורה ואחת קדימה, קבוצה הגיונית אחת. שם-
הכיתה ("progress") נשאר בצד שמאל כמו היום.)

מסך בחירת-נושא (`TopicPicker.tsx`): כרטיס-נושא ללא כפתור-📖 צמוד — הכרטיס
כולו הוא עכשיו נקודת-הכניסה היחידה, ומוביל לשיעור (לא לתרגול).

## Copy
- קישור-הדילוג: **"דלג לתרגול →"** — מילה אחת ברורה ("דלג"), לא משפט; החץ
  תואם את הכיוון-קדימה שכבר קיים ב"→ לתרגול"/"הבא →" הקיימים באותו מסך, כדי
  שהמשמעות ("זה מקדם אותך") תהיה עקבית.

## Interaction Flow
1. לחיצה על כרטיס-נושא (`reviewed`) פותחת את מסך-השיעור בעמוד-הראשון —
   בדיוק כמו שכפתור-📖 כבר עושה היום, רק שזו עכשיו הפעולה היחידה על הכרטיס.
2. "דלג לתרגול →" גלוי וזהה בכל עמוד, מהראשון ועד האחרון — לחיצה עליו
   מובילה ישר לתרגול (אותה פעולה ש-`onPractice` הקיים כבר מבצע מהעמוד
   האחרון).
3. ניווט "← הקודם"/"הבא →" הקיים בתחתית נשאר בדיוק כפי שהוא — "דלג לתרגול →"
   הוא תוספת-מקבילה בראש המסך, לא תחליף לכפתור-ה"הבא →"/"→ לתרגול" הקיים.
4. "← חזרה" ממשיך להחזיר לרשימת-הנושאים, בלי שינוי.

## Accessibility / RTL notes
אין תוכן מספרי/LTR חדש — "דלג לתרגול →" הוא מילה עברית בלבד. אותו class
(`link-button`) כמו "← חזרה" הקיים, כך שגם ה-focus-style/ה-touch-target
הקיימים חלים עליו בלי צורך בהתאמה נוספת.

## Acceptance Criteria Check
- כרטיס-נושא נכנס ישר לשיעור: yes.
- כפתור-📖 הנפרד מוסר: yes.
- דרך-דילוג מיידית מהעמוד הראשון: yes — "דלג לתרגול →" בכותרת, לא בתחתית.
- הדילוג זהה בכל עמוד: yes — חלק מהכותרת הקבועה, לא תלוי-עמוד.
- שום שינוי בתוכן/ניווט הקיים של מסך השיעור: yes — התוספת היחידה היא קישור
  אחד בכותרת.
- נושא לא-`reviewed` ללא שינוי: yes — העיצוב לא נוגע בו.
- "← חזרה" ללא שינוי: yes.
