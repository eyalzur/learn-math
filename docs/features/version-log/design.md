# לוג גרסאות — Design

## Overview
מספר הגרסה הקיים במסך הראשון הופך לכפתור. לחיצה עליו פותחת חלונית (דיאלוג מעל
המסך, כמו דיאלוג ה-⚙️ הקיים) עם רשימת גרסאות — חדשה למעלה — ולכל אחת מספר
הגרסה ותיאור שורה-שתיים של מה היה בה.

## Screens / States

### מסך ראשי (בחירת תלמיד/ה) — שינוי קטן
אותו מסך בדיוק, רק ש-"גרסה X.Y.Z" הופך מטקסט סטטי לכפתור בעל מראה דומה (לא
כפתור בולט — עדיין שולי, לא מתחרה עם "מי לומד היום?"). אפשר ללחוץ גם על
המספר וגם על המילה "גרסה".

### חלונית לוג הגרסאות (חדש)
נפתחת מעל המסך הנוכחי, כמו הדיאלוג הקיים של ⚙️ (רקע מעומעם מאחור, תוכן במרכז,
אפשר לסגור בלחיצה על ✕ או מחוץ לתוכן):

```
┌──────────────────────────────┐
│  מה היה בכל גרסה         ✕  │
│ ───────────────────────────  │
│  1.4.0   (היום)              │
│  תיאור קצר של מה היה בגרסה   │
│  הזו.                        │
│ ───────────────────────────  │
│  1.3.2                       │
│  תיאור קצר של מה היה בגרסה   │
│  הזו.                        │
│ ───────────────────────────  │
│  ...                         │
└──────────────────────────────┘
```

- סדר: חדש למעלה, ישן למטה. בלי הגבלת כמות — כל מה שיש מצטבר, נגלל אם צריך.
- שורת הגרסה הנוכחית (זו שהמכשיר פתוח עליה כרגע) מסומנת במילה "(היום)" לצד
  המספר, כדי שיהיה קל לראות בלי להשוות ידנית למספר שבמסך הראשי.
- כל שורה: מספר גרסה (כיווניות LTR — ראו למטה) + תיאור בעברית מתחתיו.
- אם יש רק גרסה אחת ברשימה (המקרה ביום שהפיצ'ר הזה עצמו נכנס), החלונית מציגה
  את השורה הבודדת הזו — לא ריקה.

## Copy
- כותרת החלונית: `מה היה בכל גרסה`
- סימון הגרסה הנוכחית: `(היום)`
- טקסט נגישות לכפתור הסגירה (aria-label), כמו בדיאלוג הקיים: `סגור`
- תיאור הגרסה הראשונה שתירשם בלוג (זו של הפיצ'ר הזה עצמו):
  `לוג גרסאות — אפשר לראות כאן מה היה בכל גרסה.`

## Interaction Flow
1. במסך הראשי, לוחצים על "גרסה X.Y.Z" (שעכשיו כפתור).
2. נפתחת חלונית הלוג מעל המסך, עם הרשימה כמתואר לעיל.
3. סוגרים בלחיצה על ✕, או בלחיצה מחוץ לתוכן החלונית — בדיוק כמו דיאלוג ה-⚙️
   הקיים — וחוזרים למסך הראשי בלי שום שינוי מצב אחר.
4. אין ניווט נוסף מתוך החלונית הזו (לא לוחצים דרכה להמשיך למשהו) — היא מסך-קצה.

## Accessibility / RTL notes
כל מספר גרסה (`1.4.0` וכו') הוא תוכן LTR מובנה בתוך עמוד RTL — בדיוק הדפוס של
`.app-version-number` הקיים היום, שכבר פתור. החלונית החדשה חייבת להשתמש באותו
אלמנט/class נפרד למספר (לא למזג אותו למחרוזת אחת עם התיאור העברי), ולוודא
`direction: ltr` + `unicode-bidi: isolate` על אלמנט המספר — בדיוק כמו
`.problem-box` ו-`.app-version-number` הקיימים. התיאור הטקסטואלי עצמו הוא
עברית רגילה, אלמנט נפרד.

## Acceptance Criteria Check
- קיימת דרך לפתוח מסך/חלונית שמציגה רשימת גרסאות עם תיאור: **yes** — כפתור
  מספר הגרסה פותח את החלונית.
- נקודת הכניסה נמצאת באזור מספר הגרסה הקיים, לא כפתור חדש ונפרד: **yes** —
  האלמנט הקיים עצמו הופך לכפתור, לא נוסף אלמנט חדש למסך.
- הגרסה הראשונה בלוג היא זו שבה הפיצ'ר נכנס, בלי שחזור רטרואקטיבי: **yes**.
- כל גרסה עתידית מצטרפת ללוג עם תיאור משלה: **yes, בכפוף להחלטת tech-lead** —
  המבנה (חלונית מציגה רשימה) תומך בכל מספר שורות; המקור בפועל של התיאורים
  (קובץ נתונים שה-`developer` מעדכן) הוא החלטה טכנית, לא עיצובית.
- מסך לא ריק אם יש רק גרסה אחת: **yes** — מוצג רואה שורה בודדת.
