# דיוק בתיאור טעות התהליך + גיוון דימוי במשוואות חיבוריות

מבני (במקום ניסוח גורף אחיד), ודימוי המשוואות החיבוריות/חיסוריות מתגוון במקום
משפט קבוע יחיד.
