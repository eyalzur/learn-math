# זום זמני בהחזקת מגע — התקרבות למחברת

מגע שנשאר במקום לרגע קצר בתחילת הכתיבה מתקרב זמנית לתצוגה ממוקדת יותר,
וחוזר בדיוק למה שהיה כשמרימים את האצבע — מחווה של התמקדות בכתיבה מקרוב.

**מיזוג `main` פנימה (2026-09-25):** `main` התקדם בינתיים (`PR #69`, יומן
מקרים שבהם המורה טעתה) בזמן שה-PR הזה חיכה לריוויו — התנגשות אמיתית ב-
`docs/features/README.md` (שתי שורות טבלה חדשות, נפתר בשמירת שתיהן) וב-
`package-lock.json` (נפתר ב-`npm install` מחדש, לא ידנית). `package.json`
עצמו לא התנגש — `main` הגיע עצמאית לאותו `1.31.0`. `build`/`lint` ירוקים,
`375/376` בריצה מלאה ונקייה — הכשל היחיד הוא אותו flake קיים-מראש
(`grade8-angles-congruence.spec.ts`) שכבר תועד ואומת כלא-קשור.
