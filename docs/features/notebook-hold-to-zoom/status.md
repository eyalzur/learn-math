# זום זמני בהחזקת מגע — התקרבות למחברת

מגע שנשאר במקום לרגע קצר בתחילת הכתיבה מתקרב זמנית לתצוגה ממוקדת יותר,
וחוזר בדיוק למה שהיה כשמרימים את האצבע — מחווה של התמקדות בכתיבה מקרוב.

## Progress — סבב ג׳ (2026-09-13): באג אמיתי ממכשיר מגע — הזום קורס באמצע כתיבה
המשתמש דיווח (בפעם השנייה/השלישית) שהזום-אין "יוצא בחזרה" באמצע כתיבה, על
מסך מגע (אצבע). לא שוחזר עם עכבר מדומה. אומת: `pointercancel` ממחוות
מגע-ממושך מתנגשות של הדפדפן (callout/הדגשת-טקסט/תפריט-הקשר), כי חלון
ההמתנה שלנו לא דוכא אותן. תוקן ב-CSS + `onContextMenu`, בלי לגעת במכונת
המצבים. ראו architecture.md, "עדכון סבב ג׳" ו-Edge Cases.

- [x] Implementation — developer — 2026-09-13 (סבב ג׳: CSS + onContextMenu נוספו, build/lint ירוקים, אומת שהערכים מגיעים ל-CSS המקומפל)

המשתמש הכריע שהמחווה צריכה להתקרב (זום-אין) בהחזקה, לא להתרחק (זום-אאוט) —

השלבים שכבר נכתבו לכיוון ההפוך נפתחים מחדש.
