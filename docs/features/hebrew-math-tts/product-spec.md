# הקראה בקול טבעי — מנגנון חדש, כולל מספרים

## Summary
מחליפים את ליבת ההקראה הקיימת (`src/data/speech.ts`) בשני שיפורים שמחוברים זה לזה:
(1) נורמליזטור חדש שמהפוך ביטוי חשבוני **כולל המספרים עצמם** למילים בעברית — לא רק
הסימנים כמו היום; (2) קול הקראה טבעי בהרבה (Google Cloud Text-to-Speech) כשיש
חיבור לרשת, עם נפילה אוטומטית ושקטה להקראת המכשיר הקיימת כשאין.

המשתמש נתן את רוב ההחלטות המוצריות/טכניות במפורש מראש (כללי ההמרה, בדיקות חובה,
שרת+cache+נפילה) — המסמך הזה מתעד אותן, לא מגלה אותן מחדש.

## Problem / Motivation
מיקה (כיתה א', עדיין לומדת לקרוא) נשענת על ההקראה כדי להבין הסבר בלי להיתקע על
קריאה עצמאית. שני דברים בהקראה הקיימת פוגעים בדיוק בזה:

1. **מספרים לא מומרים למילים בעברית בכלל** — רק הסימנים (`+`, `-` וכו') מומרים.
   ה-`20` וה-`10` ב-"20 חלקי 2 שווה 10" מגיעים למנוע ההקראה כספרות ערביות גולמיות,
   וקריאתן בפועל תלויה לגמרי במנוע/במכשיר הספציפי — לא נשלטת ולא מובטחת בעברית
   נכונה (ללא כורח להכיר מגדר דיבור ל-מספרי מנייה מול מספרי סמיכות).
2. **קול ההקראה המובנה בדפדפן נשמע מכני** בהרבה ממה שקול TTS מבוסס-עצבי מודרני
   נותן היום — בדיוק סוג הקול שמיקה עלולה להתעלם ממנו (ראו `docs/features/read-aloud/`).

## User Stories
- כתלמיד/ה שעדיין לומד/ת לקרוא, אני רוצה לשמוע גם את המספרים בביטוי חשבוני כמילים
  בעברית ברורות, לא רק את הסימנים.
- כתלמיד/ה שנשען/ת על ההקראה, אני רוצה שהקול יישמע טבעי וחם ככל האפשר.
- כתלמיד/ה, אני רוצה שההקראה תמיד תעבוד — גם בלי רשת, גם אם שרת כלשהו לא מגיב —
  ולא תישאר דוממת.

## Acceptance Criteria
- ביטוי חשבוני מוקרא כמשפט עברי שלם, כולל כל מספר כמילה (לא רק הסימנים): דוגמאות
  מדויקות ב-`docs/features/hebrew-math-tts/tests.md`.
- מינוס מבחין בין חיסור (`7 − 3` → "פחות") לסימן שלילי (`-2 + 10` → "מינוס שתיים").
- כשרשת/שרת זמינים: ההקראה משתמשת בקול Google Cloud Text-to-Speech (he-IL).
- כשאין רשת, או שהשרת לא עונה/עונה בשגיאה: ההקראה חוזרת אוטומטית ובשקט להקראת
  המכשיר הקיימת, **באותו טקסט המנורמל** — אף פעם לא דממה.
- טקסט שסונתז פעם אחת נשמר במכשיר (cache לפי hash של הטקסט המנורמל) — אותו הסבר
  לא נשלח/משולם פעמיים.
- אין מפתח API או אישור שירות של גוגל קלאוד בשום קובץ בדפדפן או בריפו.
- כל התנהגות קיימת (הפסקות בין שלבים, עצירה בלחיצה חוזרת, עצירה במעבר שאלה, בחירת
  קול איכותי, קצב/גובה צליל) ממשיכה לעבוד בדיוק כמו היום — ראו `docs/features/read-aloud/`.
- אין מסך/כפתור חדש: מדובר בשיפור שקט של מנגנון קיים, לא תכונה גלויה.

## Out of Scope
- אין בחירת קול בידי המשתמש/ת — נשאר אוטומטי לגמרי, כמו היום.
- אין הקראה SSML (הדגשות, טון מיוחד) — טקסט רגיל בלבד לכל שתי שכבות ההקראה.
- אין שינוי לתוכן המוקרא עצמו (ההסבר/השאלה) — רק לאופן שבו המספרים/הסימנים בתוכו
  הופכים למילים, ולקול שמקריא אותן.
