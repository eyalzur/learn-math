   למילים. עודכנה להשוות מול הטקסט המנורמל, לא מול טקסט המסך הגולמי.
3. **שכחתי להוסיף שורה ל-`src/data/changelog.ts`** אחרי `npm run bump:feature`
   (הסקריפט מעדכן רק את `package.json`, לא את ה-changelog) — גרם לכישלון
   `version-log.spec.ts`. תוקן.
