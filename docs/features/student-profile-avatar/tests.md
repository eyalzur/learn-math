# פרופיל תלמיד ואווטר — בדיקות

קובץ: `tests/e2e/student-profile-avatar.spec.ts` (viewport של iPhone 13, 390x664). נכתב מהאפיון.

| קריטריון | בדיקה |
|---|---|
| 1 | תלמיד ישן בלי שדה אווטר עובד; ברירת המחדל זהה אחרי טעינה חוזרת |
| 2 | צ'יפ במסך הכיתות ובבית; לא במסך השיעור/תרגול |
| 3 | המגירה צמודה לקצה הימני; נסגרת ב-✕/Escape/רקע; הפוקוס חוזר לצ'יפ; Tab נשאר בתוכה |
| 4, 5 | בחירת אווטר מתעדכנת בצ'יפ ובכרטיס, ושורדת טעינה מחדש |
| 4, 8 | 3 תרגולים אחרונים (החדש ראשון) + מעבר למסך ההתקדמות המלא |
| 6 | בחירת אווטר בדיאלוג היצירה (ואופציונלית) |
| 7 | בלי גלילת דף במסך הכיתות, בבית עם 7 נושאים, ועם המגירה פתוחה; מטרות מגע לפחות 40px |

קיימות ממשיכות לכסות: `no-scroll-screens` (כולל גובה כותרת עם הצ'יפ), יצירת תלמיד דרך הדיאלוג.
