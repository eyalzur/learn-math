# בחירת נושא והתקדמות אישית — Design

## Overview
מסך הכיתה מוחלף במסך נושאים, ומסך הרמות עובר להיות שלב שני. נוסף מסך היסטוריה
שנגיש מהמסך הראשון.

## Screens / States

### 1. מסך נושאים (חדש, המסך הראשון אחרי בחירת תלמיד/ה)
```
   ← החלף תלמיד                    שלום מיקה! · כיתה א׳
                                        ההתקדמות שלי →
                  מה נתרגל היום?
        ┌──────────────────────┐
        │  מספרים עד 20        │
        └──────────────────────┘
        ┌──────────────────────┐
        │  חיבור עד 10         │
        └──────────────────────┘
                    ...
```

### 2. מסך רמות (קיים, עכשיו בהקשר של נושא)
הכותרת היא שם הנושא במקום שם הכיתה, וכפתור החזרה מוביל למסך הנושאים.

### 3. מסך היסטוריה (חדש)
```
   ← חזרה                                        מיקה
                 ההתקדמות שלי
   ┌──────────────────────────────────────────┐
   │ חיבור עד 10 · בינוני    0/10   13.08 · 10:33 │
   └──────────────────────────────────────────┘
```
מהחדש לישן. כשאין רשומות מוצג משפט במקום מסך ריק.

### כיתות שעדיין לא הוסבו
כיתות ו' ו-ח' מדלגות על מסך הנושאים ועוברות ישר למסך הרמות, בדיוק כמו היום.

## Copy
- כותרת מסך הנושאים: `מה נתרגל היום?`
- כרטיס נושא מציג את שם הנושא בלבד. מונה הרמות הוסר: הוא היה זהה בכל הכרטיסים,
  ולכן לא עזר לבחור ביניהם, ורק הוסיף רעש למסך שילד/ה בן 7 סורקים.
- קישור להיסטוריה: `ההתקדמות שלי →`
- כותרת ההיסטוריה: `ההתקדמות שלי`
- היסטוריה ריקה: `עוד לא תרגלת. אחרי התרגול הראשון הוא יופיע כאן.`
- כפתור החזרה במסך הראשון: `← החלף תלמיד`; בכל מסך פנימי: `← חזרה`.
  הניסוח משתנה כי מהמסך הראשון "חזרה" בעצם מחליף משתמש, וכפתור צריך להגיד מה
  הוא עושה.

## Interaction Flow
1. תלמיד/ה → מסך נושאים → נושא → רמה → תרגול → תוצאה.
2. `← חזרה` מהתוצאה או מהתרגול מחזיר למסך הרמות של אותו נושא.
3. `ההתקדמות שלי →` פותח את ההיסטוריה; `← חזרה` ממנה חוזר למסך הראשון.
4. בסיום כל תרגול נרשמת רשומה, גם אם הציון 0 - התרגול קרה.

## Accessibility / RTL notes
כל המסכים החדשים הם טקסט עברי. שני מקומות מערבבים ספרות ולכן קיבלו `direction: ltr`
משלהם: הציון (`0/10`, שאחרת עלול להיקרא `10/0`) והתאריך (`13.08 · 10:33`).
מונה הרמות (`3 רמות`) הוא ספרה בודדת בתחילת מחרוזת ולכן בטוח בהקשר RTL.
