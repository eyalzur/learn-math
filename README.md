# לומדים חשבון

אפליקציית ווב ללימוד ותרגול חשבון - חיבור, חיסור, כפל וחילוק - בעברית.

## הפעלה

```bash
npm install
npm run dev
```

## מבנה הפרויקט

- `src/data/exerciseSets.ts` - תרגולים מוכנים מראש, מחולקים לפי רמת קושי
- `src/components/Home.tsx` - מסך בחירת תרגול
- `src/components/Practice.tsx` - מסך תרגול עם בדיקת תשובות ומשוב מיידי
- `src/components/Result.tsx` - מסך סיכום ציון בסוף תרגול

## טכנולוגיה

React + TypeScript + Vite.

## תהליך פיתוח פיצ'רים

בקשות לפיצ'רים חדשים עוברות דרך תהליך מתועד: הגדרת מוצר → עיצוב UX/UI → ארכיטקטורה
טכנית → מימוש → בדיקות. הסטטוס והתיעוד של כל פיצ'ר נמצאים ב-
[`docs/features/`](./docs/features/README.md).

כל פיצ'ר או תיקון מפותח בבראנץ' נפרד (`feature/<שם>` או `fix/<שם>`) ומגיע ל-`main` דרך
pull request בלבד - `main` נפרס אוטומטית לאתר החי, ולכן שום דבר לא נכנס אליו בלי שעבר
ביקורת.
