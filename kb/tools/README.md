# כלי ה-KB

פקודות (בלי LLM, בלי רשת): `npm run kb -- <index|search|lint|stale|hash|log>`.
המלא: ראשית `kb/tools/kb.mjs`. בדיקות: `npm run kb:test`.

פורמט: [OKF v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/tree/main/okf).
הכלים לא יודעים שום דבר על learn-math — `KB_ROOT=/path/to/kb` מכוון אותם לכל bundle.
