# process

* [איך מתקשרים עם המשתמש בצ'אט](/process/chat-communication.md) - תמיד בעברית, קצר, רק שורות תחתונות — התחקיר שייך לקומיטים ולתיעוד.
* [בסיס הידע (kb/) — איך משתמשים](/process/knowledge-base.md) - kb/ הוא bundle בפורמט OKF; שואלים עם /kb-ask, מוסיפים עם /kb-add, והכלים רצים בלי LLM.
* [בקשת ריוויו — ארבעה שדות, תמיד](/process/review-request.md) - כל בקשת ריוויו חייבת איפה/איך/מה אמור לקרות/מה לשפוט, ולהיות דף תצוגה ממוקד, לא הדרכה באפליקציה.
* [בראנץ' ל-PR, ומיזוג רק באישור](/process/branch-pr-merge.md) - main נפרס אוטומטית לאתר החי — אין push ישיר; PR נפתח רק אחרי בדיקות ירוקות; ממזגים רק באישור מפורש.
* [ה-pipeline של פיצ'ר](/process/pipeline.md) - כל שינוי עובר product → design → architecture → implementation → tests, וכל שלב כותב מסמך ועושה קומיט.
* [מריצים בדיקות לפני שאומרים מוכן](/process/run-tests.md) - build + lint + e2e; הריצה המקומית חייבת --workers=1 ופעם אחת בלבד.
* [פתיחת סשן: /resume-proj ו-/status](/process/session-start.md) - מתחילים ב-/resume-proj — מה פתוח, מה חסום על המשתמש, והצעה קונקרטית אחת להתחיל בה.
