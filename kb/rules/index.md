# rules

* [שמות קבועים לדמויות בדימויים: דניאל, יעל, נועם](/rules/analogy-character-names.md) - דמות בודדת מזוהה = שם אחד; שתי דמויות = שני שמות שונים; קבוצה/כמות/מספר מיקום נשארים בלי שם.
